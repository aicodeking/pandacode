# Serve your PandaCode session on any port

## Added

- **Serve the live session in any browser.** Turn on **Web access** under **Settings → Connections → Remote access**, pick any open port (`1–65535`, or `0` for an automatic port; defaults to `3737`), and open or copy the session link. Browser tabs share the same live projects, tasks, agent streams, terminals and settings as the running desktop app in real time over HTTP and WebSocket.
- **Start or move the web server from the CLI and headless host.** Launch the desktop app with `--port <port>` (and optionally `--host <addr>`, or `PANDACODE_PORT` / `PANDACODE_HOST`), or re-run with `--port <port>` to move an already-running desktop session via single-instance handoff. In headless mode, `pandacode serve --port <port>` serves the same browser UI alongside PandaCode Connect.
- **Local-by-default security and browser-mode experience.** The server binds to `127.0.0.1` by default, requires a fresh per-run 256-bit bearer token (passed in the URL `#token=` fragment and stripped from the address bar on load, with one-click token rotation), validates `Host` and `Origin` headers, rate-limits failed auth, and enforces a strict command allowlist. Native-only actions adapt cleanly in browser tabs: folder and file pickers fall back to keyboard-accessible path prompts, external links open in the browser, desktop-only voice input and crash-report folder actions are hidden, and stopping or moving the server confirms before disconnecting active tabs.

## Known limitations

- Verified locally on macOS (Apple silicon) with Rust unit tests, strict Clippy, the Node unit, design-token and release tests, the website build, and the Chromium and WebKit Playwright suites for the web bridge and Web access settings. Windows and Linux packages are covered by the GitHub Actions release builds and their startup smoke checks.
- The built-in web server speaks plain HTTP without TLS. Keep it on loopback (`127.0.0.1`) and forward over SSH (`ssh -L <port>:127.0.0.1:<port> <host>`) or a private Tailscale/WireGuard network rather than exposing it directly on an untrusted LAN.
- Browser tabs do not support desktop-only OS integrations such as local voice dictation or native OS file dialogs (use the built-in path prompt instead).
