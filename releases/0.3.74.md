# Readable traces for every PandaCode tool

## New

- **PandaCode's own tools read as sentences.** All 84 of PandaCode's tools (team, tasks, VMs, simulators, design canvas, preview and browser, cloud CLI, code search, bots, moodboards and Jev) now have their own row and result card instead of a generic "Used PandaCode" line. Examples: "Dispatched 2 workers" shows the roster with each worker's model, files and status. Team messages show as bubbles. Cloud CLI commands get a terminal card with the exit code. VM commands name their machine ("Ran uname -a · on ubuntu-dev").
- **Subagent cards.** A running subagent is one compact line. A finished one shows its result first, with the prompt one click away.
- **Other MCP tools** show their arguments as a short table, and list results as lists. Branded servers keep their logos.
- **Truthful group headers.** A group counts only finished calls and shows running and failed calls separately ("Operated 4 VM actions · 1 failed"). A command that exits with an error now marks its row and its group as failed.

## Changed

- Raw tool data appears only when a card leaves something out. Rows with nothing more to show are plain lines.
- Failed actions lead with the failure ("Couldn't create fedora-box") instead of reading as a success.

## Known limitations

- Tools from MCP servers PandaCode doesn't recognise still use the generic argument and result card.
