# Unified typography and corner radii

## Improved

- **One typography hierarchy across the workspace and standalone windows.** Conversation threads, the sidebar, Settings, dialogs, Markdown previews, Generative UI cards, the Quick Launcher, the menu-bar popover and the pinned running-agents widget now share an eight-role type scale (`display`, `title`, `heading`, `subheading`, `body`, `prose`, `meta`, `caption`) with consistent weights, line heights, letter spacing and UI scaling (`1.0×`–`1.6×`). Inline `code`, `samp` and `tt` scale proportionally with surrounding prose while fenced code blocks keep the mono scale, and terminal defaults read directly from the computed mono tokens.
- **Unified corner-radius scale and concentric nesting.** Cards, nested panels, controls, chips, popovers, pills and split buttons follow one radius scale with automatic modal dialog step-down (while keeping in-dialog image and progress viewer plates and portaled menus/tooltips at their own radii) and consistent concentric nesting across Markdown blockquotes, admonitions, code blocks and Generative UI surfaces.
- **Consistent `<select>` controls across light, dark, RTL and forced-colors modes.** Single-line dropdowns in the workspace, Shadow DOM forms and the Quick Launcher share one chevron token, RTL alignment and padding, while multi-line selects grow naturally and forced-colors mode restores the native system arrow cleanly.
- **Stable segmented controls and tab bars.** Segmented controls and horizontal tab bars stay at regular body weight in every state so labels never shift or jitter when switching options.

## Fixed

- **Markdown and Shadow DOM typography parity.** Aligned heading sizes, table column and row header weights, inline code and bold sizing, task-list alignment and KaTeX math clipping across Light DOM Markdown, README and file previews, rich-HTML blocks and Generative UI Shadow DOM cards.
- **Layout and clipping at larger UI scales.** Fixed clipping and overflow in model-picker effort rows, brand letter tiles, queued message rows, sidebar headers and compact composer surfaces up to `1.6×` UI scale.

## Known limitations

- Verified locally on macOS (Apple silicon) with Chromium, WebKit, Rust unit tests, strict Clippy and the website build. Windows and Linux packages are covered by the GitHub Actions release builds and their startup smoke checks.
- Native macOS WKWebView appearance is covered by automated Playwright WebKit checks and GitHub Actions macOS builds.
