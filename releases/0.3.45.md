# Sidebar sections and a slimmer inspector

## New

- **Active and Needs review in the sidebar.** Threads whose agent is running or waiting for your approval are listed under **Active** at the top. Threads that finished in the last day while you were in another thread are listed under **Needs review** until you open them.
- **Completed threads.** A tick on any row marks the thread complete and moves it to a **Completed** section at the bottom of the sidebar, which starts collapsed and remembers whether you left it open. The filled tick on a completed thread reopens it.
- **Archive and delete from the sidebar.** Hover a row for archive and a … menu with Mark complete, Archive and Delete task…, which work on any thread, not only the open one. The archive view offers Restore and Delete.
- **Tabs in the inspector.** The inspector's icon bar is now one slim strip of tabs with icons and names, level with the window header. **+** adds any other view (Files, Search, Browser, Pull request, Simulators, VMs, Design), each tab has a close button, and your open tabs are remembered. **Changes** is the only tab open at first.
- **Diffs right in Changes.** Changes shows every changed file's diff stacked in one scrolling list, with a slim header for the scope (all, unstaged or staged), file count, added and removed lines, and the branch. Each file has its own header with its status and a … menu to stage, open or copy it. Stage all, Commit… and Create isolated worktree… are in the header's … menu. Diffs refresh while an agent keeps editing a file.

## Known limitations

- The Jujutsu chip for repositories that also use Git no longer appears in Changes.
- Tested in the browser preview and unit tests on macOS (Apple silicon); the new tab strip and Changes view were not tried in a packaged build on Windows or Linux before release.
