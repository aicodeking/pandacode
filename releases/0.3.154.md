# Queue hold fixes, reconnect stream recovery, and release script hardening

## Fixed

- **Queued follow-ups on desktop bot threads no longer stay stuck after a failed turn.** Automatic run-end queue holds on the desktop now apply only to ordinary tasks (matching the host), while explicit queue holds are still honored for bot conversations.
- **Dismissing a usage limit no longer strands queued follow-ups without a Resume button.** Clearing a usage limit on desktop or headless now transitions a usage-limit pause so **Resume** appears immediately without auto-sending queued messages.
- **Reconnecting a browser tab clears stale running indicators and refreshes background queues.** If a disconnect misses a turn's completion, reconnecting clears the stuck **Stop** button and loads the saved reply (while preserving newer live output), and queued follow-ups added to background threads while offline appear as soon as you switch to them.
- **Headless `pandacode serve` keeps queued follow-ups from racing usage-limit recovery.** Automatic limit-reset continuations now launch before clearing resumable holds so a pending queue drain cannot jump ahead of recovery, and a failed continuation launch preserves any existing hold.

## Known limitations

- **Local web access (`--port`) ([`docs/headless.md`](https://github.com/aicodeking/pandacode/blob/v0.3.154/docs/headless.md#local-web-ui---port)).** The `#token=` URL grants full control of the PandaCode session as the host user (including starting agents, running terminal commands, and editing workspace files). The built-in web server speaks plain HTTP, so keep it on loopback (`127.0.0.1`) or reach it over an SSH tunnel, Tailscale, or WireGuard rather than exposing it on an untrusted network. Host-only capabilities — local voice dictation, the embedded browser, native clipboard access, and OS file/tray actions — are unavailable in browser tabs.
- **SBOM scan coverage ([`SBOM-COVERAGE.json`](https://github.com/aicodeking/pandacode/releases/download/v0.3.154/SBOM-COVERAGE.json), [`SBOM-COVERAGE.md`](https://github.com/aicodeking/pandacode/releases/download/v0.3.154/SBOM-COVERAGE.md)).** Desktop build dependency scans (`pandacode-rust.cdx.json` and `pandacode-npm.cdx.json`) report 0 Critical and 0 High findings, with pre-existing lower-severity counts of 2 Medium and 3 Low in Rust and 6 Low in npm. Four compressed installers (`PandaCode-macOS-arm64.dmg`, `PandaCode-macOS-x64.dmg`, `PandaCode-Linux-x86_64.AppImage`, and `PandaCode-Linux-aarch64.AppImage`) remain `not-scanned` because `syft` cannot inspect components inside them, and the Windows setup `.exe` and macOS `.app.tar.gz` artifact inventories identify only 2 metadata components each.
- **Public website changelog deployment.** The public changelog at `https://pandacode.bambooed.ai/changelog/` is deployed separately from GitHub Releases via Cloudflare Workers (`website/README.md`) and currently serves an earlier release (`v0.3.32`) until redeployed; GitHub Releases and the in-app updater carry the current release notes.

## Verification

- **Local macOS (Apple silicon):** Rust `message_queue`, `headless`, `web_server`, and `bots` library unit tests (175 passed, 1 ignored live-network test), Clippy (`--all-targets -- -D warnings`), `npm run build`, Node unit tests (1,471 passed), release-script tests (104 passed), website build, Playwright Chromium queue and web-bridge suites (`web-bridge`, `message-queue`, `queue-parity`, `steering`, `usage-limit`: 63 passed), and Playwright WebKit `web-bridge` suite (23 passed).
- **GitHub Actions CI and release:** `ci.yml` runs the full Rust library test suite on Linux, per-platform Clippy (`-D warnings`) on macOS, Windows, and Linux, TypeScript/unit tests, website build, and ONNX parity on macOS. `release.yml` requires a verified artifact-only preflight (`verify_preflight` checking installer checksums, updater signatures, and `latest.json` with `publish` skipped and best-effort SBOM download), guards published tag targets against commit mismatches, runs release CLIs safely across symlinked paths, enforces Developer ID signing, notarization, stapling, and Gatekeeper verification for both `PandaCode.app` and `.dmg` installers on official macOS builds (while keeping signing optional for local builds and forks without signing secrets), and runs Windows and Linux packaged startup smoke checks (confirming launch and stay-alive, not full GUI rendering).
