# Google Colab runtime fix

## Fixed

- **Starting and stopping Google Colab runtimes works again.** Creating a runtime (from Settings, the VM panel, Cloud Agents or the `pandacode_colab_*` and `pandacode_vm_*` tools) and stopping one no longer fails with `Google Colab returned HTTP 411.` These requests have an empty body, and the HTTP client left out the `Content-Length` header for it, which Google Colab's servers require on every `POST`. PandaCode now sends an explicit `Content-Length: 0` on these requests.

## Also included from 0.3.143

0.3.143 was not published separately, so its unified typography and corner-radius changes ship in this release. Full details are in [the 0.3.143 notes](https://github.com/aicodeking/pandacode/blob/main/releases/0.3.143.md).

- **One typography hierarchy.** Threads, the sidebar, Settings, dialogs, Markdown previews, Generative UI cards, the Quick Launcher, the menu-bar popover and the pinned running-agents widget share an eight-role type scale with consistent weights, line heights, letter spacing and UI scaling (`1.0×`–`1.6×`). Inline code scales with the surrounding prose, while fenced code blocks keep the mono scale.
- **Unified corner radii.** Cards, nested panels, controls, chips, popovers, pills and split buttons follow one radius scale, with a step-down inside modal dialogs and consistent concentric nesting in Markdown and Generative UI surfaces.
- **Consistent `<select>` controls and stable segmented controls.** Dropdowns share one chevron, RTL alignment and padding across light, dark, RTL and forced-colors modes. Segmented controls and tab bars keep a regular weight in every state, so labels no longer shift when you switch options.
- **Markdown and Shadow DOM typography parity, and no clipping at larger UI scales.** Headings, table headers, inline code, task lists and KaTeX math now look the same in Markdown, README and file previews, rich-HTML blocks and Generative UI cards. Model-picker effort rows, brand letter tiles, queued message rows, sidebar headers and compact composer surfaces no longer clip or overflow at up to `1.6×` UI scale.

## Known limitations

- Verified locally on macOS (Apple silicon) with Rust unit tests, strict Clippy, the Node test suites and the website build. Windows and Linux packages are covered by the GitHub Actions release builds and their startup smoke checks.
- Native macOS WKWebView appearance for the 0.3.143 typography and radius changes is covered by automated Playwright WebKit checks and GitHub Actions macOS builds.
- The Colab fix was tested against a loopback mock that rejects a `POST` without `Content-Length` the way Google Colab does. Live GPU and TPU quotas, idle timeouts and OAuth client availability depend on your Google Colab account and tier.
- Colab runtimes are temporary. An idle runtime is held for roughly 90 minutes before it expires, and stopping a runtime discards its unsaved files and kernel state.
