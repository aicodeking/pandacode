# Hardened SQLite startup recovery, legacy bot upgrades, and release-note links

Not published as a standalone GitHub Release; all changes below shipped bundled inside [v0.3.161](https://github.com/aicodeking/pandacode/releases/tag/v0.3.161).

## Fixed

- **Subagent restart recovery handles malformed or non-array tool lists safely.** `settle_subagent_set!` now guards non-object elements and missing, `null`, or non-array `$.tools` values instead of raising malformed JSON errors or wrapping `null` into `[null]`.
- **Team startup recovery accepts valid JSON5 snapshots and guards non-array worker lists.** `architect_team_meta`, `INTERRUPT_TEAMS_SQL`, and `LEGACY_PROMPT_CUTOFF_SQL` now validate `architect_teams` snapshots with `json_valid(..., 6)` and guard non-array `$.workers`, matching the existing project-deletion and agent-update guards.
- **Legacy bot schema upgrades stay resilient on partial or mixed-case tables.** `bots::has_bot_column` now matches column names case-insensitively (`COLLATE NOCASE`), and `bots::upgrade_schema` installs table and column upgrades independently of optional secondary indexes so partial legacy bot tables never roll back `bots` column additions.
- **Fixed broken `v0.3.155` links and disclosures.** Updated four `v0.3.155` documentation and SBOM links in [`releases/0.3.155.md`](https://github.com/aicodeking/pandacode/blob/v0.3.161/releases/0.3.155.md) to point to `v0.3.156` (where `0.3.155`'s SQLite work shipped) and added explicit untested-platform disclosures.

## Upgrade and compatibility

- **Schema version stays at `37` with full rollback compatibility.** `PRAGMA user_version` remains `37`. The additive triggers and trackers (`running_tools`, `running_subagents`, `architect_team_meta`) remain compatible with `0.3.151`–`0.3.158` rollbacks and preserve `user_version > 37` databases without issuing persistent schema or index DDL.

## Known limitations

- **Local web access (`--port`) ([`docs/headless.md`](https://github.com/aicodeking/pandacode/blob/v0.3.161/docs/headless.md#local-web-ui---port)).** The `#token=` URL grants full control of the PandaCode session as the host user (including starting agents, running terminal commands, and editing workspace files). The built-in web server speaks plain HTTP, so keep it on loopback (`127.0.0.1`) or reach it over an SSH tunnel, Tailscale, or WireGuard rather than exposing it on an untrusted network. Host-only capabilities — local voice dictation, the embedded browser, native clipboard access, and OS file/tray actions — are unavailable in browser tabs.
- **SBOM scan coverage ([`SBOM-COVERAGE.json`](https://github.com/aicodeking/pandacode/releases/download/v0.3.161/SBOM-COVERAGE.json), [`SBOM-COVERAGE.md`](https://github.com/aicodeking/pandacode/releases/download/v0.3.161/SBOM-COVERAGE.md)).** Desktop runtime dependencies are unchanged from `v0.3.156`, whose lockfile SBOM scans (`pandacode-rust.cdx.json` and `pandacode-npm.cdx.json`) reported 0 Critical and 0 High findings, with pre-existing lower-severity counts of 2 Medium and 3 Low in Rust and 6 Low in npm. Four compressed installers (`PandaCode-macOS-arm64.dmg`, `PandaCode-macOS-x64.dmg`, `PandaCode-Linux-x86_64.AppImage`, and `PandaCode-Linux-aarch64.AppImage`) remain `not-scanned` because `syft` cannot inspect components inside them, and the Windows setup `.exe` and macOS `.app.tar.gz` artifact inventories cover package metadata only.
- **Public website changelog deployment.** The public changelog at `https://pandacode.bambooed.ai/changelog/` is deployed separately from GitHub Releases via Cloudflare Workers (`website/README.md`); GitHub Releases (linked from Settings → About) and the `latest.json` updater manifest carry the current release notes immediately.

## Verification

- **Local macOS (Apple silicon):** Full Rust library test suite (`cargo test --profile fast-release --locked --lib -- --test-threads=4`: 4,110 passed, 0 failed, 113 ignored), Clippy (`--profile fast-release --locked --all-targets -- -D warnings`), `npm run build`, Node unit tests (`npm test`: 1,471 passed, 0 failed), release-script tests (`npm run test:release`: 107 passed, 0 failed), `AGENTS.md` checks (`node --test tests/agents-md.test.mjs`: 2 passed, 0 failed), and website build (`npm run site:build`).
- **GitHub Actions CI and release:** `ci.yml` runs the full Rust library test suite on Linux, per-platform Clippy (`-D warnings`) on macOS, Windows, and Linux, TypeScript/unit tests, website build, and ONNX parity on macOS. `release.yml` requires a verified artifact-only preflight (`verify_preflight` checking installer checksums, version-bound updater signatures across all six platforms, and `latest.json` with `publish` skipped), guards published tag targets against commit mismatches, enforces Developer ID signing, notarization, stapling, and Gatekeeper verification (`codesign`, `stapler`, and `spctl`) for both `PandaCode.app` and `.dmg` installers on official macOS builds (while keeping signing optional for local builds and forks without signing secrets), and runs Windows and Linux packaged startup smoke checks (confirming launch and stay-alive only, not full GUI rendering).
- **Not interactively tested on physical hardware:** macOS Intel (`darwin-x86_64`), Windows x64 (`windows-x86_64`), Windows arm64 (`windows-aarch64`), Linux x64 (`linux-x86_64`), and Linux arm64 (`linux-aarch64`) were not interactively tested on physical hardware; the packaged macOS Apple silicon `.dmg` is verified during official release builds via `codesign`, `stapler`, and `spctl` rather than locally packaged in this pass.
