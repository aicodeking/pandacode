# SBOM vulnerability details and scan timestamps

## Changed

- **Detailed SBOM security reports.** Release security reports (`SBOM-COVERAGE.json` and `SBOM-COVERAGE.md`) now record the vulnerability database build timestamp (`vulnerabilityDbBuilt`) after the scan downloads the database and list each Critical and High advisory by ID, package and version. See [Local web UI](https://github.com/aicodeking/pandacode/blob/v0.3.148/docs/headless.md#local-web-ui---port) for full browser-session setup, flags (`--port`/`--web-port`, `--host`/`--web-host`; default port `47322`, or `0` for an automatic port) and environment variables (`PANDACODE_WEB_PORT`/`PANDACODE_WEB_HOST`).

## Known limitations

- Verified locally on macOS (Apple silicon) with Rust unit tests, strict Clippy, the Node unit, design-token and release tests, the website build, and the Chromium and WebKit Playwright suites for the web bridge and Web access settings. Windows and Linux packages are covered by the GitHub Actions release builds and their startup smoke checks.
- **Session link is a full-control credential.** Anyone with the `#token=` URL has full control of your PandaCode session as the host user. CLI startup (`pandacode serve --port` or initial `--port`) prints the link to stdout (which service managers may log), and browser history can retain the initial `#token=` URL even though the page strips it from the address bar on load. Rotate the token at any time with **New token** under **Settings → Connections → Remote access → Web access** (or restart the server) to invalidate prior links.
- **Plain HTTP off loopback.** The built-in web server speaks plain HTTP without TLS. Keep it on loopback (`127.0.0.1`) and forward over SSH (`ssh -L <port>:127.0.0.1:<port> <host>`) or a private Tailscale/WireGuard network rather than exposing it directly on an untrusted LAN.
- **Desktop-only integrations.** Browser tabs do not support local voice dictation or native OS file dialogs (use the built-in path prompt instead).
- **SBOM scan coverage and reviewed exceptions (`SBOM-COVERAGE.json`).** Compressed installers (`PandaCode-macOS-arm64.dmg`, `PandaCode-macOS-x64.dmg`, `PandaCode-Linux-x86_64.AppImage`, `PandaCode-Linux-aarch64.AppImage`) are reported as `not-scanned` because `syft` finds no identifiable components inside them; build dependencies are inventoried in `pandacode-rust.cdx.json` and `pandacode-npm.cdx.json`.
