# 0.3.126 again, replacing the withdrawn 0.3.128

## Changed

- **This release is 0.3.126 with a new version number.** 0.3.128 was withdrawn. PandaCode never updates to a lower version, so copies that installed 0.3.128 need a higher number to move off it. 0.3.129 contains the same code as 0.3.126.
- **The changes from 0.3.128 are not in this release.** That covers warm spares for faster model and harness switching, the lower idle CPU and memory work, and the sky and long-thread changes. They will return in a later release.

## Known limitations

- If you are on 0.3.126, this update changes nothing except the version number.
