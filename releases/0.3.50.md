# Agent traces you can follow

## New

- **Live agent traces.** While an agent works, each tool call reads as a short sentence on a thin rail, like "Searched [Slack] for messages since yesterday" or "Read [main.ts]". The header shows the step that is running now. The two newest results stay open as cards and older ones fold away. When the answer arrives, the turn folds into one line such as "Ran 2 searches and read 3 sources" with the sources' icons.
- **Result cards for every tool.** Shell commands show the command, its exit code and the last lines of output. Edits show a small diff, and searches show the matching files and lines. There are also cards for web searches and fetched pages, plans and todo lists, subagents, skills, PandaCode's own team tools, and other MCP tools. A running tool shows a single status line. Each card's raw input and output sit behind a small `</>` button.
- **Brand marks and source chips.** Slack, Gmail, GitHub, Linear, Granola, Notion and a dozen more show their own marks. Links to them in an answer become small source chips.
- **Smoother streaming.** A half-written link or code span streams as text instead of pausing the answer.

## Changed

- PandaCode still turns animation off everywhere else. The live trace is the one exception, and it turns off when your system asks for reduced motion.

## Known limitations

- The trace's line breaks every five steps in very long turns.
- Long lines in file-read cards end in "…" instead of scrolling.
- File cards show full paths rather than paths relative to the project.
