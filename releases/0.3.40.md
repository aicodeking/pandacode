# Update modes, per-connection usage and a tidier picker

## New

- **Notify me updates** (Settings → About → Updates): choose Automatic, Notify me or Off. Notify me checks for new versions and asks before it installs and restarts. Your current setting carries over.
- **Usage per connection**: the Usage dialog shows each named connection on its own (for example two Claude plans). When a plan hits its limit, the banner offers **Continue on <connection>** for the other connections of the same harness. The task then continues in a fresh session that carries the conversation.
- **Jev on OpenRouter**: Jev's decision model can now run through OpenRouter with your own key, with a dropdown of compatible models. TypeSafe stays the default.
- **InstaBox machine image**: once InstaBox is connected, Settings → Cloud lets you start new machines from one of your snapshots instead of `agent-browser` (thanks @WyrdWerk).
- **InstaBox keep-awake**: machines stay awake during a run and their connections recover after a pause.
- **Cline**: an interactive console, its capabilities and version checks.
- The inspector's icon bar now sits on the panel's top edge.

## Fixes

- Opening PandaCode while it is already running brings the open window forward instead of starting a second copy on the same data.
- The harness picker only lists harnesses that are installed (plus the task's current one).
- Check updates now lists every detected agent, including Oh My Pi, Kilo and Cline. Agents without an automatic update route show "Manual update".
- GLM Coding Plan and MiMo Token Plan moved from the Agents tab to Providers, and OpenCode's model list has one home (Settings → Agents). The Providers tab explains how providers relate to agents.
- Linux: a copy that is not running as an AppImage (unpacked, or installed from a package) no longer overwrites its own program when updating; it only tells you a new version exists.
- Linux AppImage: a `GDK_BACKEND` you set yourself is kept (for example `GDK_BACKEND=wayland`); X11 stays the default.
- Linux: pages from the Browser pane open in your system browser instead of in a broken pane at the bottom of the window that flickered on resize.
- Switching a task to another connection now starts a fresh session instead of trying to resume one from another account.
- Windows: the Rust test suite runs again.

## Known limitations

- Linux: the Browser pane can't show pages inside PandaCode yet, so element picking, screenshots and the agents' browser tools aren't available there.
- Usage for named connections is read for Claude Code (and GLM/MiMo) and Codex; other harnesses' connections show that their limits aren't read separately.
- Oh My Pi lists every model it has credentials for, including API keys set in your shell. Use omp's `enabledModels` setting to shorten the list.
- The Linux changes were not tried on a Linux machine before release.
