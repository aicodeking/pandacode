# Voice dictation with on-device speech models

## New

- **Dictate into the composer.** Press the microphone button (or ⌘⇧D / Ctrl⇧D) and the prompt box becomes a live, scrolling waveform while you speak. Press Stop or Enter and the box is back at once, so you can keep typing while the speech is transcribed; the text lands where you were typing. Escape cancels. The shortcut can toggle, hold to record, or do both.
- **Transcripts are never lost.** If a transcription fails, the recording is kept so you can retry it. If you edit the draft heavily while it is being transcribed, the text is offered for review instead of being dropped in the wrong place. Switching threads or closing the window (when PandaCode keeps running) stops the recording and still delivers the text.
- **Settings → Voice.** A new page with:
  - **Input:** choose a microphone, test it with a live level meter and playback, and pick the shortcut behaviour.
  - **Transcription:** send audio to an on-device model, a speech service, or turn voice off, and choose a language.
  - **A model browser:** search languages and models, see each model's accuracy grade and error rate per language, speed, size and licence, then download, test, select or delete it.
  - **Speech services:** use OpenAI, Groq, Mistral or any OpenAI-compatible endpoint with your own key (kept in PandaCode's secret store).
- **On-device speech.** Models run on your computer with transcribe.cpp (Metal on Apple silicon, CPU elsewhere), so audio never leaves it. Downloads come from Hugging Face, resume after interruption and are checked against a SHA-256 checksum before use.

## Changed

- When a send fails, your draft is now always put back, ahead of anything you typed since. Before, it came back only if nothing new had been typed. This applies to every send, not only dictated text.
- Settings now has nine sections; Voice sits between Appearance and Agents.
- Settings → About has a **Third-party notices** button that opens the licences bundled with the app.

## Privacy

- Nothing is recorded until you start dictation, and nothing is uploaded unless you choose a speech service. Model downloads contact `huggingface.co` (and its `*.huggingface.co` / `*.hf.co` download hosts) only when you press Download. Both are listed in the README privacy table.

## Known limitations

- On-device models need a processor with the Armv8.2 dot-product and i8mm instructions on Windows on Arm; older Snapdragon 8cx laptops are told to use a speech service instead.
- On Linux the AppImage uses the system's ALSA library (`libasound.so.2`) for the microphone.
- Tested in the browser preview (Chromium and WebKit) and with the native Rust test suite. A real microphone, the macOS permission prompt and real speech providers have not been tested by hand on every platform, and the new Windows, Intel Mac and Linux on Arm speech-engine builds run for the first time in this release's CI.
