# Voice dictation with on-device speech models

## New

- **Dictate into the composer.** Press the microphone button, or ⌘/Ctrl+Shift+D while focus is in the prompt box, on the microphone button or on the dictation status card, and the prompt box becomes a live, scrolling waveform while you speak. Press Stop or Enter and the box is back at once, so you can keep typing while the speech is transcribed; the text lands where you were typing. Escape cancels a recording. The shortcut can toggle, hold to record, or do both.
- Dictation never sends automatically: review the draft and send it yourself. When a recording reaches two minutes or 16 MiB it stops; press **Transcribe recording** to transcribe it. If nothing is set up yet, the first microphone click opens Settings → Voice.
- **Transcripts aren't dropped.** If a transcription fails, the recording is kept so you can retry it, until you discard it or quit PandaCode. If you edit the draft heavily while it is being transcribed, the text is offered for review instead of being dropped in the wrong place. Switching threads, or closing the window while PandaCode keeps running, stops the recording and still delivers the text. When closing the window quits PandaCode (Linux, or no menu-bar item), or when you quit the app, a dictation that is still recording is cancelled and its audio isn't uploaded; audio already sent to a speech service for transcription can't be recalled.
- **Settings → Voice.** A new page with three cards:
  - **Input:** choose a microphone, test it with a live level meter and playback, and pick the shortcut behaviour.
  - **Transcription:** send audio to an on-device model, a speech service, or turn voice off, and choose a language. The model browser sits here: search languages and models, see each model's accuracy grade and error rate per language, speed, size and licence, then download, test, select or delete it.
  - **Speech services:** presets for OpenAI, Groq and Mistral with your own key (kept in PandaCode's secret store), or **Local or custom server**: a full transcription URL that accepts a multipart file and model upload, such as a whisper.cpp server; the key is optional.
- **On-device speech.** Models run on your computer with transcribe.cpp (Metal on Apple silicon, CPU elsewhere), so audio never leaves it. Downloads come from Hugging Face, resume after interruption and are checked against a SHA-256 checksum before use.

## Changed

- When a send fails, your draft is now always put back, ahead of anything you typed since. Before, it came back only if nothing new had been typed. This applies to every send, not only dictated text.
- Settings now has nine sections; Voice sits between Appearance and Agents.
- Settings → About has a **Third-party notices** button that opens the licences bundled with the app.

## Privacy

- Nothing is recorded until you start dictation or run a microphone or model test, and nothing is uploaded unless you choose a speech service. Model downloads contact `huggingface.co` (and its `*.huggingface.co` / `*.hf.co` download hosts) only when you press Download. Both are listed in the README privacy table.

## Known limitations

- On-device models need a processor with the Armv8.2 dot-product and i8mm instructions on Windows on Arm; older Snapdragon 8cx laptops are told to use a speech service instead.
- The Windows on Arm i8mm check uses a processor-feature id that older Windows 11 builds don't report, so on those builds even capable processors (such as Snapdragon X) are told they can't run on-device models. Updating Windows, or using a speech service, resolves it.
- On Linux the AppImage uses the system's ALSA library (`libasound.so.2`) for the microphone.
- Tested in the browser preview (Chromium and WebKit) and with the native Rust test suite. Installers for all six platforms built and are attached, but the speech engine hasn't been run on Windows, Intel Mac or Linux on Arm hardware, and the installers haven't been tested by hand. A real microphone, the macOS permission prompt and real speech providers have not been tested by hand on every platform.
