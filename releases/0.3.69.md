# Subtle motion, a calmer toast, and a Running agents widget

## New

- **Subtle motion.** Dialogs, panes, menus and the toast move again, briefly: a few pixels over about a fifth of a second. Hover and press feedback eases instead of snapping. Nothing waits for an animation, and Reduce Motion in your system settings turns it off.
- **Sidebar rows.** The selected task has a slim accent bar at its left edge. Each row's **⋯** button opens the same task menu as a right-click.
- **A toast that stays out of the way.** Notices appear as a small glass note in the bottom-right corner. Long messages and paths wrap instead of running off the screen. A notice stays while the pointer rests on it.
- **Running agents widget.** A header button shows how many agents are working. Click it for the list of every running task, with its project, model, status (running, waiting for approval, waiting for input) and elapsed time. Click a row to open that task. **Pin** keeps the list in a small floating window that stays on screen above other apps. You can turn the widget off in Settings → General → Running agents widget.
