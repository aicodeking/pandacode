# Tool calls that read like sentences

## New

- **Every tool call reads as one short sentence.** Shell commands, file reads and edits, searches, web fetches and MCP tools now show what they did: `Read main.ts lines 3130–3220`, `Searched for “isImeKey” in src`, `Ran tests playwright · 119 passed`, `Committed “fix: tidy rows”`, `Waited for server.log to contain “ready”`. Compound commands lead with the step that mattered and fold the rest into `+N more commands`. This works for every harness, including older threads.
- **Honest failures and risks.** Failed steps read `Couldn't force-push origin x` or `Tests failed · 3 of 120` in the failure colour, even when a pipe hid the exit code. Destructive steps (`rm -rf ~`, `git reset --hard`, `terraform apply -auto-approve`, `pulumi up --yes`) carry a `destructive` badge with the reason in a tooltip. Deleting scratch folders such as `.work/` or `/tmp` is not flagged, and a step that never ran is not blamed.
- **Image thumbnails in tool rows.** Screenshots and images an agent views or produces show a small thumbnail beside the file name. That includes Read of a PNG, Codex `imageView`, Playwright and PIL scripts, `ffmpeg` and `sips`. Click a thumbnail for a full viewer with Reveal and Copy. Thumbnails also appear in the team workers panel and in the launcher.
- **Better cards and summaries.** Expanded cards show the useful part, such as the diff (an edit that failed is marked "Not applied"), test tallies, search results or the command. Group headers summarise in plain English, like "Read 3 files, edited 2 files and ran 4 commands".
- **Rows fit narrow windows.** At narrow widths the object and quote shrink first, then the `+N more` tail, so the verb, badges and exit code stay visible.

## Privacy and security

- Thumbnails are served by a new local `tool_image` command. It only loads an image that the same task's own tool records name: an image the agent viewed, or one a finished command wrote. Relative paths must stay inside the task's checkout, network paths are never loaded, symlinks are not followed, and images are size-capped and downscaled. Nothing is sent over the network.

## Known limitations

- Images saved by a script piped in from another command (`cat <<EOF | python3`) don't get a thumbnail. Only the last literal path a script saves is shown on the row.
- Some row wording is a best guess. When a compound command fails, the card names the step that most likely failed, but that isn't certain.
- Checked with unit tests (TypeScript and Rust) and the Chromium browser specs for the tool rows and image viewer. Not clicked through by hand in the packaged app on every platform.
