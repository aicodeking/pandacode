# PandaCode on your phone

## New

- **A mobile app for iOS and Android** (`mobile/`, built with Expo). Sign in with the same GitHub account as PandaCode Connect, and see and control the tasks running on your computers from your phone. Tasks never run on the phone.
  - Task lists for each computer, grouped by project, with live status and search.
  - Live transcripts with Markdown, folded tool calls, and approval and question cards.
  - Send, queue, steer and stop, and change the model, effort and permissions.
  - Start new tasks in any project on a computer.
  - Native Liquid Glass on iOS 26, with solid fallbacks on older iOS and a Material look on Android.
- **Desktop support for phones.** A computer with remote control on now lists its tasks and projects for trusted devices. It also starts tasks in a project that isn't on GitHub, and still shows an approval or question that was already waiting when the phone opened the task.

## Known limitations

- The app isn't in the App Store or Play Store yet. Build it from `mobile/` with your relay URL and GitHub client ID (see `mobile/README.md`).
- Each computer must trust the phone in Settings → Remote access, and the phone must trust the computer.
- Images can't be attached from the phone yet.
