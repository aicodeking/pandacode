# Task tools everywhere and steadier replies

## Fixed

- Task tools are now available to every supported harness and to team leads, not only some of them (#331).
- The thread header keeps the theme colour under accessibility display preferences, with imported light and dark themes too (#338).
- Streaming and final replies stay in view while they arrive and as they become saved history, and typing in the composer does less layout work (#333).
- Arabic and Hebrew prose is shown right to left automatically, decided per block; code and math stay left to right (#342).
- Keyboard shortcuts such as ⌘K, ⌘N and ⌘F now work on non-English keyboard layouts, while IME conversions keep their keys (thanks to PR #337).
- Inspector panels recover after a task fails to load instead of staying on Loading.
- Release security scans retry transient scanner downloads, and any missing scan coverage is reported explicitly instead of looking clean.

## Known limitations

- Reduced layout work while typing lowers CPU use, but high CPU on some Linux systems during long sessions may not be fully resolved.
- An inspector that fails to load a task now recovers, but other causes of a stuck inspector reported in #340 may remain.
- Packaged native installers have not been manually exercised on real hardware for this release.
