# Quieter panels and bigger Oh My Pi catalogs

## Fixes

- **New tasks no longer open the right panel.** If you close the panel, new tasks keep it closed until you open it again. Tasks you have opened before still remember their own panel state.
- **Oh My Pi loads large model catalogs.** PandaCode now asks omp to send big replies in pieces (omp's RPC protocol v2) and puts them back together, so long model lists no longer fail with "RPC response exceeded the transport limit". When a catalog still fails, the model picker shows the agent's own reason (#91).
- **Remote access never overwrites a secrets file it cannot read.** If PandaCode Connect's file is unreadable or damaged, saving a sign-in now fails with an error instead of replacing your token and device key. Two PandaCode windows saving at once no longer lose an update (#106).

## Known limitations

- The panel choice is remembered only while PandaCode runs; after a restart the first new task opens the panel again until you close it.
- Oh My Pi's chunked replies were tested with recorded frames, not a live omp install.
