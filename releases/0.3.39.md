# Safer PandaCode Connect

## New

- **Full access for remote tasks** (Settings → Remote access, off by default). While it's off, a phone or another computer can't start, prompt or switch a task into Full access on this computer; remote tasks started without a mode ask for approvals.

## Fixes

- Replies and live updates from a computer are now stamped and checked, so an old message can't be replayed to your phone or other computer.
- A request from a device that was removed, or that arrived just before you turned off remote control, no longer runs.
- Device fingerprints are longer (128 bits).
- The Connect relay caps sign-in requests, limits sign-ins overall, and makes sure a removed device's old sign-in can't come back.

## Known limitations

- Update every computer: a phone or computer on this version can't control a computer that is still on an older one until it updates.
- Any device signed in to your GitHub account can still control a computer while **Allow remote control** is on. Only turn it on where you need it.
