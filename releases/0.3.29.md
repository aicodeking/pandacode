# No more Keychain prompts for remote access

## Fixes

- **PandaCode Connect no longer asks for your Keychain password.** macOS tied each saved Connect secret to the exact build that saved it, so every update asked for your login password again on each launch. Remote access now keeps its sign-in and device key in a private file in PandaCode's data folder that only your user account can read, so no Keychain prompt appears at launch or after updates.

## Known limitations

- **Sign in to remote access once more after updating** (Settings → Remote access). This computer appears as a new device: mark your computers **Trusted** on each other again and revoke the old entry.
- Keys you save for bots, cloud sandboxes and providers still live in the Keychain.
