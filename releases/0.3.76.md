# Lighter over long sessions

## Changed

- **Memory stays flat over long sessions.** Things PandaCode loaded once and kept forever are now released when they're no longer needed:
  - The Panda Router model unloads after 10 idle minutes and reloads in the background when a team routes again.
  - Usage records hold each model name once, are dropped when idle, and a run end now reads only that task's logs instead of rescanning all of them and rewriting the whole cache file.
  - PandaCode Connect keeps at most 8 MB of event history for phones, stored as text, and drops a finished task's history 10 minutes after no phone is watching.
  - When the last agent finishes, freed memory is handed back to the system.
- **Lighter window.**
  - The Markdown parser stays at about 16 MB after very large messages (it used to grow to 40–64 MB and stay there); the output is identical.
  - Live streams no longer copy their whole text for every chunk.
  - Hidden design-canvas artboards are unloaded and come back when you open the canvas.
  - Documents in file tabs you aren't viewing take at most 64 MB in total; older ones re-read their file when you open them.
  - An open worker transcript keeps 200 messages; older ones load as you scroll up.
  - Model and slash-command lists drop stale entries.

## Known limitations

- After scrolling far back in a long worker transcript, returning to the bottom shows the newest 100 messages; older ones load again as you scroll.
- A project untouched for 30 minutes shows only PandaCode's own slash commands until its list refreshes.
- These changes target memory that builds up over long sessions; they have been measured in tests, not yet in a long real-world session.
