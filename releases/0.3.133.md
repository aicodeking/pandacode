# Smoother startup and less background work

- PandaCode restores your workspace while it checks which coding tools are installed and fills in their versions. You can open a new task during startup. Send waits for a pending model choice to save, and edits made during that wait stay in the composer until you send them.
- The Files pane and open file tabs check for external saves every few seconds while visible, even beside another app. Hidden views stop polling, and repeated output from a running command no longer triggers extra refreshes.
- Wallpapers keep moving with fewer redraws at rest. When rendering stays expensive, translucent panels switch to solid fills. Streaming replies grow without briefly jumping back to an earlier height.
- Deploy requests for different targets open their own tasks, even when you pick a second target while the first is opening.

## Known limitations

Foreground memory use and system load during active agent runs are still unmeasured. The solid fill can remain active until rendering shows sustained recovery.
