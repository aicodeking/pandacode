# Quieter sky, project files, ZCode teams, and current VM screenshots

## Added

- **Project explorer and floating editor.** The Files tab is a tree of the project. Create, rename, and delete files and folders (delete asks first), copy a path, and reveal a file in the system file manager. Opening a file keeps a tab in a floating editor with syntax highlighting, save, and Ask or Fix on the selected code. Saves stay inside the project: a link cannot redirect a write or a delete outside the checkout. Thanks to @SUP3RMASS1VE.
- **ZCode in agent teams.** ZCode workers and a ZCode lead now get PandaCode's team tools. Switching a team's model to ZCode keeps the team. Thanks to @zj-linjie.

## Fixed

- **VM screenshots stay current.** A quiet virtual machine no longer returns the previous screen. A capture reads updates that were already waiting, then waits for its own request. A resize keeps the frame when that update already contains the whole new screen. Thanks to @chesedo.
- **Scrolling and typing over the sky stay responsive.** The turn card, composer, and thread tiles over an animated sky are a plain fill, so the page does not re-blur the sky on every frame and scroll step. Wallpaper frost is unchanged. The sky also holds still for a moment while you scroll or type, and paints more slowly while a reply is streaming. Thanks to @ehab-oss.

## Known limitations

- The sky pause happens on every machine, including ones where the blur was already cheap. It is a short hold, then the sky moves again.
- A file or folder name from the explorer cannot contain a slash, a backslash, or a colon, and cannot be named `.git`.
- Opening a project file in the default app hands that file to the operating system's handler.
