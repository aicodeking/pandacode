# Sidebar polish

## Fixed

- **Row actions in the sidebar no longer sit on a solid block.** Hovering a task showed the tick and ⋯ buttons on a lighter rectangle over wallpapers. They now sit on a soft frosted blur that fades into the row, selected or not. With Reduce Transparency on, they keep a solid background.
- **New task no longer opens a settled task.** After removing the worktree of a task you hadn't sent yet (for example Merge into main, then the cleanup offer), the next New task opened that settled task with "Reopen task" instead of a fresh one. It now always starts a new task.
