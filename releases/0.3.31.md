# Cloud agents

## New

- **Run an agent in the cloud.** In a New task, open the **Run on** menu (beside Local / Worktree) and pick a connected cloud provider. The agent runs on a machine in your own account: Daytona, Cloudflare, AWS EC2, Google Cloud, E2B, Modal, Vercel Sandbox, CodeSandbox, Runloop, Blaxel, Tensorlake, Freestyle or boat.
- **Set up for you.** PandaCode creates the machine, installs Git, Node and the agent's CLI (Claude Code, GLM, MiMo, Codex or OpenCode), copies your login before every run, and uploads your checkout, uncommitted changes included.
- **Works like any task.** Streaming, approvals, questions, steering, the queue and the model picker all work as they do locally. A status strip shows each stage (Installing, Running, Reconnecting, Syncing) with Sync, Retry, Open, Stop and Delete machine.
- **Close the laptop.** The run keeps going on the machine, and quitting PandaCode doesn't stop it. When you come back, the task catches up and finishes normally.
- **Changes come home.** After each run the work lands in a local worktree on `pandacode/cloud-<id>`, so the Changes tab, pull requests and Run work as usual. Idle machines stop on their own after about 15 minutes; the next prompt starts them again or recreates them from your local copy.
- **Settings → Cloud** has connect forms for every new provider, Vercel Sandbox and Google Cloud options, and an optional long-lived Claude token (`claude setup-token`) for cloud agents. See [cloud agents](https://github.com/aicodeking/pandacode/blob/main/docs/cloud-agents.md).

## Known limitations

- The provider integrations were built from each provider's API docs and tested against mocks, not live accounts. Please report anything that fails on first use.
- Railway can't run commands on a machine, so it can't host agents. CodeSandbox works only on VMs that offer its Pint connection.
- Modal sandboxes last at most 24 hours from creation; Tensorlake's unattended time depends on your plan.
- Copying your local Claude login (instead of using a `claude setup-token` token) may sign you out on this computer if the cloud copy refreshes it.
- On providers without a file API, copied logins travel inside the setup command and could briefly appear in that machine's process list.
- Existing Cloudflare sandbox users should redeploy the Worker from Settings → Cloud.
- Images and browser captures can't be sent to a cloud task yet.
