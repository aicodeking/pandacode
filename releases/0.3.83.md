# One switch for agent telemetry

## Added

- **Turn off agent telemetry in one place.** Settings → Agents → Privacy → **Turn off agent telemetry** (off by default) starts every agent with its vendor's own opt-outs, plus `DO_NOT_TRACK=1`. That covers Claude Code, Codex, Kimi, Grok, DeepSeek, Command Code, Pi, Muse and OpenCode sharing. Your agent config files are not changed.
  - **Each agent's row shows what the switch does there:** turned off, set in the agent's own settings, or no verified switch.
  - It applies everywhere PandaCode starts an agent: tasks, pre-started follow-up turns, the terminal, cloud agents, model and command discovery, and agent updates. Changing it starts the next turn fresh.

## Known limitations

- Cline has no per-launch switch, so turn its telemetry off in Cline's own settings.
- With the switch on, Claude Code stops fetching remote feature flags (it uses its defaults) and can't take sessions started remotely on this computer.
- Agents without a verified opt-out (for example Antigravity) still get `DO_NOT_TRACK=1`, but PandaCode can't confirm they honor it.
