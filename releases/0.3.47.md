# Faster, richer PandaCode Connect for the iPhone app

This release is the desktop half of the PandaCode iPhone app. The phone talks to your computer over PandaCode Connect, and these changes on the computer let it show more and answer faster.

## New

- **Team tasks stay working.** A team task stays under Running on the phone until its last worker finishes, with "Waiting on 3 workers", instead of looking done when the architect ends its turn. Stop on the phone pauses the whole team, the same as the Stop button here.
- **Team workers on the phone.** The phone can show a task's team: each worker's status, checkpoint, summary and full transcript, plus the latest team messages, updated live.
- **Pull requests, changes and bots.** The phone can show a task's linked pull request, its file changes, and your bots.
- **Images in messages.** Images you attach to a message are kept with it, so the phone can show them later.
- **Sub-agents and last activity.** Task rows tell the phone what sub-agents are doing and when the run last did something, so stalled runs are easy to spot.
- **Project icons** are sent to the phone.

## Faster

- Threads open newest-first, so long threads appear at once.
- Your computer answers up to four read requests from the phone at the same time; sending, stopping and approving keep their strict order.
- Database work no longer holds up other requests, GitHub pull request lookups are kept for 30 seconds, and replies no longer wait for the next update tick.
- A combined request can carry up to eight reads in one round trip.

## Known limitations

- The new phone features need this version on the computer; older versions show "Update PandaCode on <computer>" where something is missing.
- Tested with unit tests and the browser suite on macOS (Apple silicon); the team status and speed-ups were not timed between a real phone and computer before release.
