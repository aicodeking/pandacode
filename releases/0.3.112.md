# A warning before you quit running agents

## New

- **PandaCode asks before quitting while agents are running.** Quitting stops every agent running on your computer, so a quit from the menu, ⌘Q, the menu bar item or closing the window (where that quits) now shows a warning with the number of running agents. Choose **Quit** to stop them and quit, or **Cancel** to keep working. Nothing is asked when no agent is running, when only cloud agents are running (they keep going on their machines), or when PandaCode restarts to install an update.

## Fixed

- **Linux: a tidier microphone list.** Settings → Voice lists sound cards by name; a raw ALSA device id is listed only when it is your saved microphone or when card names can't be read.
- **Linux: a saved `jack` or `oss` microphone that can't be opened** now records from the system default instead of showing an error.

## Known limitations

- The quit warning was checked with unit tests of when it appears and what it says, and by reading the code paths that lead to a quit. It has not been clicked through by hand in the built app on any platform.
- `pandacode serve` has no window and never asks.
- The Linux microphone fixes were checked with unit tests, not with a real Linux microphone.
