# PandaCode Connect fixes

## Fixed

- **Follow-up prompts on another computer.** A task started on another computer accepted its first prompt, then refused every later one with "This task runs on <computer>." With Team turned on by default, the task also got a team, and follow-ups went to that team on this computer. Tasks on another computer now always send to that computer, and the Team button is hidden on them.
- The composer no longer stays in the running state when a late event arrives after a remote run ends.

## New

- **Start progress for another computer.** While the other computer gets a new task ready, a strip above the composer shows the computer and each stage: finding the project, downloading the repository (with git's percent as a progress bar), preparing and starting the agent. If the start fails, the strip shows the error with Retry and Dismiss, and your message stays in the prompt.
- **Images and screenshots on another computer.** Pasted images, image files and browser screenshots now go with the first prompt and with follow-ups, up to four per message. They are sent in small encrypted pieces. The other computer accepts only PNG, JPEG or WebP images it was just sent, up to 5 MB each, and stores them under its own names.

## Known limitations

- Moodboards still can't be sent to another computer.
- Tested in the preview and unit tests on macOS (Apple silicon); a start and images between two real computers were not tried before release.
