# Faster model and harness switching

This release builds on 0.3.133 with instant model, harness, effort, and permission switching backed by warm agent spares, cached model catalogs, and reliable draft preservation across held sends and `/btw` side threads.

## Added

- **Warm agent spares.** PandaCode starts an idle agent ahead after a reply finishes, on a model, harness, effort, or permission pick in a local task, and when you begin typing a draft in a local task. At most two idle spares are kept across all harnesses and expire after 10 minutes.
- **Live Claude Code switches.** Picking an explicit model, reasoning effort, or non-**Full access** permission mode updates a waiting Claude Code process over its control channel without restarting it, and falls back to a fresh start if refused.
- **Background handshake and Codex thread preloading.** **Codex** and supported Agent Client Protocol (ACP) harnesses (**Kimi**, **OpenCode**, **Grok**, **DeepSeek**, **Command Code**, **Kilo**, **GitHub Copilot**, **Devin**, and **Hermes**) spawn and complete `initialize` ahead of your prompt, keyed to your working folder, environment, and watched login or configuration files. Local Codex tasks with an existing conversation also preload `thread/resume` without sending a turn.
- **Cold-launch racing and cancellation.** Sending a message while a handshake spare is still starting races it against a cold launch after a short grace window so a slow spare never holds up a turn; a spare that fails early falls back immediately, and a failed cold contender reports its error without launching a second time. Superseded, discarded, or disabled starts cancel immediately and terminate their process groups.
- **Start agents ahead setting.** **Settings → Agents → Start agents ahead** (on by default) controls all background agent preparation; turning it off stops any starting or waiting spare right away.

## Changed

- **Instant model, harness, effort, and permission picks.** Composer choices show immediately and save in the background. Effort changes queue in order without blocking model rows or further effort picks. Leaving a named team by picking its lead model keeps your chosen reasoning effort; switching to another model or harness resets effort to **Default**; a **ZCode** pick joins an automatic team instead of leaving it.
- **Cached model and team catalogs.** Hovering or focusing the model button preloads the picker, and model and team lists open immediately from a 5-minute cache while refreshing in the background. Failed refreshes keep the saved list with a **Couldn't refresh** note and wait 30 seconds before retrying, updates wait while the pointer rests over the model list so rows do not jump, and **Esc** and picker keys ignore active IME composition.
- **Held sends and `/btw` draft recovery.** Sending from the main composer or `/btw`, starting from the board, continuing past a usage limit, **Keep fixing** in Council, and reopening **Model** or **Permissions** wait for an in-flight preference save before acting. Held `/btw` sends and unsent side-thread drafts stay recoverable across reloads, project moves (including moving a New task to **No project**), and refusals in submission order, and multi-line drafts split along line boundaries keep trailing newlines and blank chunks within the 1 MB total draft budget.

## Fixed

- **Picked models, efforts, and permissions stick.** Task list refreshes read before a pick no longer revert the button or flicker back. Model and permission changes save one at a time in pick order, an in-flight effort settling behind a queued new-model switch does not overwrite the new model's effort or corrupt rollback on refusal, and navigating away and back or moving a `/btw` side thread to a full thread mid-save still clears busy indicators, restores refused labels, and loads the **Switched harness** handoff card.
- **Empty composer and `/wake` edge cases during a save.** Pressing **Enter** on an empty prompt during an in-flight switch no longer marks the send button busy, shows a false refusal toast, or auto-sends text typed later, and pressing **Enter** repeatedly on `/wake` during a save dispatches once.
- **Re-picking the current model just closes the picker.** Choosing the model already in use changes nothing and starts nothing (except inside a named team, where picking its lead model leaves the team) and returns focus to the composer in the main thread or `/btw` side panel.
- **Steady busy pulses and single refusal notices.** The pulse on **Model**, **Permissions**, and **Send** keeps its phase across composer redraws. When a held send, board start, side thread, **Continue**, **Keep fixing**, picker team or speed row, or **Team** toggle was waiting on a refused change, one notice explains what stayed instead of replacing earlier notices.
- **Warm-agent lifecycle fixes.** Picking a harness as a reply finishes keeps its own spare instead of letting the end-of-turn prewarm replace it; in-place model, permission, roster, and Council updates retain compatible spares; stale running tasks reconcile instead of refusing a switch; and exited spares are dropped instead of handed a turn.

## Privacy

- **Local CLI preparation only.** When **Start agents ahead** is on, PandaCode starts only the agent CLIs you installed and selected, and sends no user prompt (local Codex tasks with a saved thread load that conversation ahead without sending a turn). Starting a CLI can still connect to its provider and run startup hooks, plugins, or MCP servers from your own configuration; **Turn off agent telemetry** still applies. Model catalog caching keeps lists in memory only and never polls in the background.
- **No new automatic network requests.** Held draft recovery uses the same local web storage as other unsent drafts and respects **Keep unsent drafts** and **Clear saved drafts**.

## Known limitations

- Warm spares are not started for key-based Claude Code relays (**GLM Coding Plan**, **MiMo Token Plan**, **Alibaba Token Plan**), **Antigravity**, **Cline**, **Cursor**, **ZCode**, **Muse**, **Pi**, or **omp**, nor for cloud tasks, Connect remote mirrors, agent-team leads and workers, `/btw` side-thread picks, or skill, `/goal`, `/compact`, and `/review` turns.
- Switching a waiting Claude Code spare to or from the `default` model alias, into or out of **Full access**, or across fast-mode or conversation changes restarts the spare instead of updating it in place. OpenCode 2.x sign-ins stored in `opencode.db` are not watched by file key.
- End-to-end switching latency against live provider servers has not been benchmarked, and desktop installers were not built or tested on native machines before CI.
