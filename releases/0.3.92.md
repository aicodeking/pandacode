# A new look, a sky in every thread, and tiled threads

## New

- **A full redesign.** Every page now shares one design system: hairline borders, soft shadows, calmer type and neutral primary buttons, in dark, light and imported VS Code themes.
- **The thread is a window.** The conversation shows a live scene that follows your local clock, and its clouds drift faster while an agent works and part around your pointer. There are eight scenes (sky, alpine, aurora, dunes, lagoon, nebula, ocean and rain), and each thread keeps its own. Wallpapers are still here, as a switch in Settings → Appearance, off by default.
- **One card per agent turn.** The header shows the running step and elapsed time. The latest reply sits inside, shortened with Read more, and changed files open the diff from the footer. Bot threads and the By the way panel keep their chat rows.
- **Tile up to six threads.** Drag a thread from the sidebar, ⌘/Ctrl-click it, or choose Open beside in its menu to see threads side by side inside the thread area. The focused tile is the full thread and the others are read-only views that update live. ⌘⌥←/→ moves focus between them.
- **State colours.** Access modes, Team, Saver, remote machines and worktrees each have their own colour when on, and icons replace labels in the prompt box to save space.

## Changed

- The prompt box is one card, with the model, mode, Team, Saver, computer, checkout and branch on a single row. The project name and context meter are gone from it; `/status` still reports context use.
- The action dock floats over the thread and no longer takes a column of its own.
- ⌘+ and ⌘− scale the whole interface, not just the text.
- Settings is grouped into seven sections, with row help behind info marks.
- Connected cloud providers lead the Cloud sandboxes page. Unconnected one-key providers sit in a More cloud machines fold.
- The sidebar's sections no longer have an inner panel, and the open thread's row is a raised card.

## Known limitations

- Scenes are drawn with WebGL at a reduced resolution and pause when hidden, but several tiles each run their own scene, so tiling many threads costs more GPU time.
- A read-only tile is a view of its thread: to type or approve in one, click it to focus it.
- The By the way panel draws chat rows, so a side thread opened as a full thread shows its turns as cards instead.
- The new design and scenes were tested in Chrome and WebKit previews. Tile corners and scene rendering in the installed app have not been checked on a real machine for this release, and neither has a real agent streaming into an unfocused tile.
