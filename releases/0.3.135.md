# 0.3.133 again, replacing the withdrawn 0.3.134

## Changed

- **This release is 0.3.133 with a new version number.** 0.3.134 was withdrawn. PandaCode never updates to a lower version, so copies that installed 0.3.134 need a higher number to move off it. 0.3.135 contains the same code as 0.3.133.
- **The changes from 0.3.134 are not in this release.** That covers warm agent spares, background handshakes and Codex thread preloading, live Claude Code model, effort and permission switches, cached model and team catalogs, instant composer picks, and the held-send and `/btw` draft recovery that came with them. The **Start agents ahead** setting goes with them, since 0.3.133 never starts an agent ahead. They will return in a later release.
- **Draft limits return to 0.3.133's.** Unsent drafts are kept up to 50,000 characters per draft, as the README and the privacy page say again.

## Known limitations

- If you are on 0.3.133, this update changes nothing except the version number.
