# Turn-card containment, team workflow fixes, and community PRs

## Fixed

- **Turn cards stay self-contained.** Changed-files summaries and team Workers lists no longer leak outside `.turn-card` in card threads — late or steered change snapshots fold cleanly into their turn card footer, changes-only turns wrap inside their own card, completed work materializes ahead of newer steer bubbles, and live Workers stay inside the card even without a `dispatch_workers` tool row.
- **Queued steering reaches team leads immediately (#384).** When all team workers settle, ready queued user messages are drained atomically, saved to the transcript, and prepended to the lead's wake prompt ahead of worker results while respecting paused queues and active usage limits.
- **Usage-limit resets unblock queues cleanly (#375).** Tasks re-check their usage limit at reset time even without automatic resume enabled, restoring the explicit **Resume** button without spamming sidebar redraws.
- **Run `/status` mid-turn (#385).** `/status` (along with other safe slash commands) now works while an agent is actively running and keeps context token counts current.
- **Clearer OpenCode authentication errors (#391).** OpenCode prompt `-32000` authentication failures now name the selected or default model that lacks credentials instead of telling you to sign in to the OpenCode CLI, while keeping standard sign-in guidance for other ACP harnesses.
- **Agent usage stays readable with the Browser tab open (#387).** Opening the Browser tab no longer blocks Agent usage commands from reading the main webview.
- **Menu bar reopens a closed workspace window (#386).** Clicking the tray/menu bar item rebuilds the workspace window if it was closed.
- **Hardening fixes (#406, #407).** Fixed a `jj` path parsing panic when `}` appears before `{` in a filename, and bounds-checked AWS AgentCore event-stream headers against malformed frames.

## Added

- **Still sky setting (#323).** Settings → Appearance now includes a **Still sky** toggle (when Wallpapers is off) to hold the procedural sky as a calm still frame without continuous cloud or pointer animation.
- **Saved teams in the Team menu (#383).** Saved named teams and Classic profiles can now be picked directly from the composer's Team menu alongside automatic Agent Teams, with an **Architect & workers…** entry so Classic and Automatic setups work side by side.
- **Alibaba Token Plan models (#401).** Added stable `qwen4-max` and `deepseek-v4.1-flash-1017` to the built-in Alibaba catalog while preserving `qwen4-max-preview` for existing tasks ahead of its November 25 retirement.
- **Resizable and maximizable terminal drawer (#362).** Drag or use keyboard controls to resize the terminal drawer, remember its height across sessions, or maximize it while keeping the action dock and composer clear.
- **Pi usage tracking (#399).** Reads local Pi harness session logs for usage costs and per-task token counts.
- **ZCode extras and import (#262, #319).** Displays ZCode subagents and checkpoints in the transcript and supports importing conversations from the ZCode desktop client.
- **DigitalOcean region and size pickers (#293).** Choose DigitalOcean regions and machine sizes from cached dropdowns.
- **Local Laya decisions in Jev (#302).** Supports loopback local decision servers in the Jev add-on.
- **Locale-independent crash-notice tests (#403).** Pinned crash-notice formatting tests so unit tests pass outside `en-US` locales.

## Known limitations

- Tested locally on macOS (Apple Silicon) across Chromium, WebKit, Rust unit tests, strict Clippy, and the website build; Windows and Linux packages are verified by GitHub Actions release builds and startup smoke checks.
