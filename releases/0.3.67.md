# Files beside the thread, model thinking, and community fixes

## New

- **Files open in the right sidebar.** Opening a file from a link, an @-mention, Changes, Search, Files or an attachment now opens it in an **Open files** tab in the inspector. The conversation stays visible.
- **Thinking text.** While an agent reasons, a folded **Thinking** block above its answer shows the text (Claude, Codex, ACP harnesses, Pi, Muse). (#197)
- **New harnesses:** ZCode (#165) and Hermes Agent (#177).
- **Environment variables for harnesses**, globally and per provider (#157).
- **Headless server mode** with `pandacode serve` (#161).
- **Cloud agents** in Docker containers and on DigitalOcean, Vultr, Hetzner and RunPod over SSH (#173).
- **Netlify** deploy target (#149).
- **Usage:** DeepSeek balance in the usage panel (#175), measured per-task token usage beside the saver estimate (#187), and an offer to tighten the token saver as context fills (#183).
- **Push notifications** on the phone for approvals and finished tasks, off by default (#191).

## Fixed

- The Settled section in the sidebar now uses the sidebar's own color instead of a darker block.
- Kimi Code K3.x models offer Low, High and Max thinking levels instead of only On (#141).
- Reasoning efforts for every DeepSeek model (#198, #196), and OpenCode efforts listed from least to most (#193).
- iOS Simulator taps work when a device profile has no screen size, such as iPhone 18 Pro on iOS 27 (#145).
- Linux: the AppImage no longer freezes on launch on systems with the COLRv1 emoji font (#179).
- Pi models are found from unquoted Windows launchers (#146).
- Team setup shows a busy state right away (#151); skills import menus follow the theme (#150); Kilo Code and Oh My Pi logos (#152); update-cache edge test (#98).

## Known limitations

- The iOS 27 simulator fix and the Linux font fix could not be tested on those exact systems before release.
- OpenCode's "Default" model shows no effort control, because OpenCode reports its default model's efforts only inside a session.
