# Clearer Linux microphone errors

## Fixed

- **Linux: a clearer error when no microphone opens.** When a saved `jack` or `oss` microphone can't be opened, dictation records from the system default instead. If the default input can't be opened either, the error now names both problems, not just the second one.

## Known limitations

- On a Linux machine with a working default input, CI now checks that a saved `jack` microphone falls back to it and records. The case where the default input fails too was checked by reading the code, not on a real machine.
