# Fast and Ultra Fast in the model picker, and Alibaba Token Plan

## New

- **Speed in the model picker.** Under Effort, a Speed row offers Standard plus every faster tier the selected model supports, and the model button shows your choice (for example "High · Fast").
  - **Codex:** the tiers come from Codex's own model catalog, so Fast shows wherever Codex offers it, and Ultra Fast shows for models where Codex lists it.
  - **Claude Code:** models that Claude Code marks as supporting fast mode get Fast. A change made while a Claude task runs applies from its next turn.
  - Models without a faster tier don't show the row.
- **Alibaba Token Plan.** A new provider that runs your installed Claude Code against Alibaba Cloud Model Studio's Token Plan, using Qwen 3.8 Max and Qwen 3.8 Flash in Claude Code's model slots. Other Token Plan text models (Qwen, DeepSeek, GLM) are in the picker. Add your Token Plan key (it starts with `sk-sp-`) in Settings → Agents → Provider connections, or set `ALIBABA_TOKEN_PLAN_API_KEY`. Your own Claude Code settings are not changed.

## Fixed

- **`/fast` shows the right state.** `/fast` with no argument now sees Fast as on when it is on. Before, it always read as off, so it could only turn Fast on.

## Known limitations

- Alibaba Token Plan uses the Singapore endpoint only, which is the region Alibaba documents for the plan. It runs on this computer, not on cloud machines, and the mobile app doesn't list it yet.
- The Alibaba logo in the app is a placeholder.
