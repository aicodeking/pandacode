# Fix for the voice crash on macOS

## Fixed

- **Voice no longer crashes PandaCode on macOS.** In 0.3.108, opening Settings → Voice or clicking the microphone closed the app. The audio library had a memory bug that only appeared in release builds, so it got past testing. PandaCode now uses a corrected version, and your saved microphone choice is kept.

## Changed

- When a recording stops on its own at the limit, or the microphone stops, the message now names the **Transcribe recording** button.
- If the on-device speech engine stops unexpectedly, the message now suggests a speech service if it keeps happening.

## Known limitations

- A release build has now recorded from a real microphone on Apple silicon. The microphone permission prompt, real speech services, and real microphones on other platforms have not been tested by hand. Everything else listed under Known limitations in the 0.3.108 notes still applies.
