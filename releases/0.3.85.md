# /btw side threads

## New

- **Ask a side question without interrupting the agent.** Start a prompt with `/btw` to open a side thread in the new **By the way** tab on the right. It runs in the same project, harness, model and checkout, and the main agent keeps working: `/btw` never queues to or steers it, even while it runs.
- **The side thread knows what the main thread is doing.** Each side message carries a "Main thread context" attachment with the main thread's title, status and what's new since the last side message, including a reply still being written. It is capped at 24 KB and says when older text was left out.
- **A panel built for quick questions.** The side conversation streams in the tab with its own prompt. Insert an answer into the main prompt, open the side thread as a full thread, or start a new one. Later `/btw` messages reuse the same side thread, and the tab comes back when you return to the main thread. Esc in the panel returns to the main prompt and never stops the main agent.

## Changed

- PandaCode's `/btw` replaces the `/btw` commands that Codex and Kimi provided.

## Known limitations

- `/btw` is refused when the prompt has attachments, for tasks that run on another computer or a cloud machine, and in bot conversations.
- In a worktree task the side thread is a copy of the conversation, so the main thread needs at least one sent message first.
- The side prompt can't send while the side agent is answering.
- Side threads are listed in the sidebar as ordinary tasks titled `BTW: …`, and their links to main threads are kept per window.
