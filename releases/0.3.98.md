# Tiling and queue drags work in the app, and one reply is one card

## Added

- **Recommended settings.** Settings now opens on a Recommended tab. It shows which suggested settings are on and takes you to the page for each one. It never changes anything for you.

## Changed

- **Reorder the queue by dragging.** The up and down arrows are gone. Drag a queued message to its place; a line shows where it will land. Alt+↑/↓ still works from the keyboard. **Send now** has a forward arrow, so it can't be mistaken for a move button.
- **The running agents widget is now opt-in.** The button at the top right of the window switches off once for everyone with this update, and a pinned floating window closes. Turn it back on in Settings → General → Running agents widget, and it stays on.
- **One card for a lead's whole reply.** When a team lead wakes to check or review its workers, its work stays in one response card, both while it runs and afterwards. Earlier steps wait in a closed fold, so the card doesn't get long. The time shown is work time and leaves out time spent waiting on workers. Thread tiles show the same single card.
- **New look for the model picker.** Harnesses sit directly on the popover and models in one inset panel, and effort uses the same control as Settings. The picker is a little wider, so custom model rows keep their harness name and team rows keep their worker count.
- **New look for the design iteration popover.** The pill, card and large view now match the rest of the app.

## Fixed

- **Tiling and sidebar drags in the installed app.** Dragging a thread to tile it or reorder it did nothing in the app, even though it worked in a browser. Drags inside the window now work. Files dropped from your computer keep working as before.
- **Clicking Model right after New task.** The picker opened on the task you were leaving, then closed, and a model picked in that moment changed the old task. It now opens on the new task.
- **Keyboard focus in the design iteration popover.** Collapsing or expanding it with a click no longer loses focus on macOS.

## Known limitations

- These changes were tested in the Chrome and WebKit previews, not in the installed app with a real agent or team lead running.
- When a lead wakes and its earlier history takes more than 300 ms to load, two cards can show briefly until it arrives.
- The permission mode menu may have the same timing problem as the Model button right after New task. This comes from reading the code and hasn't been tested.
- If an agent update finishes while the model picker is open, the picker keeps its old harness list until you reopen it.
