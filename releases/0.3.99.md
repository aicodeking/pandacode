# One changed-files row for a lead's whole reply

## Fixed

- **One changes row per reply.** In 0.3.98, when a team lead ran more than once for the same message, its response card showed a separate changed-files row for each run. It now shows one row for the whole reply, with one Run button.
  - Each file is listed once, under its latest name. A file added in one run and removed in a later one drops out, and a note says so.
  - The line counts add up each run's changes, so a file changed in more than one run is labelled "summed" and may net out to fewer lines.
  - Opening a file changed in several runs shows one tab per run, each with that run's own changes.
  - **Review with Jev** reviews the run you're viewing.

## Known limitations

- The combined row adds up line counts rather than showing the true net change, which would need a new native command.
- If every file a lead changed was added and then removed again, the card shows no changes row, so those diffs can't be opened from it.
- Tested in the Chrome preview with sample data, not yet in the installed app or with real saved changes.
