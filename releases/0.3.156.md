# Host-driven limit dismissal, full reconnect stream cleanup, and version-bound Linux signatures

## Fixed

- **Dismissing a usage limit stays consistent across desktop, browser tabs, and PandaConnect.** Clearing a usage limit from PandaConnect (`usage.clearLimit`) now transitions a `"limited"` queue hold to `"reset"` without auto-sending (matching desktop and web), and the frontend no longer issues a follow-up `set_queue_hold` RPC after `clear_usage_limit`, eliminating a race where a slow response from one client could re-hold a queue another client had just resumed.
- **Reconnecting a browser tab cleans up all stale and deleted-session run state.** Reconnect stream reconciliation now inspects every active local stream (including sessions deleted on the host while offline), clears stale `runEndings`, pending steers, subagent state, By the Way panel state, and tiles when a turn ended or was removed during disconnect, and preserves pending reconciliation if a concurrent reload supersedes the fetch mid-flight.
- **Linux updater signatures are cryptographically bound to the release version.** Repacked Linux AppImages are now re-signed with `--app-version <version>`, `verify-publish.mjs` rejects any updater signature missing or mismatching `version:<version>` in its verified minisign trusted comment, and signed release install notes no longer claim `npx pandacode` locally re-signs notarized macOS builds.

## Also included from unpublished `0.3.155`

Because `0.3.155` was not published as a separate GitHub Release, users upgrading from `v0.3.154` also receive the SQLite database performance and upgrade-safety work documented in [`releases/0.3.155.md`](https://github.com/aicodeking/pandacode/blob/v0.3.156/releases/0.3.155.md):

- **Faster startup and everyday SQLite operations.** Adds hot-query indexes and `running_tools`, `running_subagents`, and `architect_team_meta` trackers while keeping `PRAGMA user_version = 37` for rollback compatibility with `0.3.151`–`0.3.154` (45 of 54 paired benchmark cases faster; see [`docs/db-benchmarks.md`](https://github.com/aicodeking/pandacode/blob/v0.3.156/docs/db-benchmarks.md)). First launch installs the additive indexes and trackers synchronously once.

## Known limitations

- **Local web access (`--port`) ([`docs/headless.md`](https://github.com/aicodeking/pandacode/blob/v0.3.156/docs/headless.md#local-web-ui---port)).** The `#token=` URL grants full control of the PandaCode session as the host user (including starting agents, running terminal commands, and editing workspace files). The built-in web server speaks plain HTTP, so keep it on loopback (`127.0.0.1`) or reach it over an SSH tunnel, Tailscale, or WireGuard rather than exposing it on an untrusted network. Host-only capabilities — local voice dictation, the embedded browser, native clipboard access, and OS file/tray actions — are unavailable in browser tabs.
- **SQLite trade-offs from `0.3.155`.** A few write-heavy paths (`delete_project_cascade`, batched remote-mirror subagent writes, and small team-snapshot saves) measured slower in benchmarks, malformed team snapshots fail closed on agent updates and project removal, and bot activity logs are trimmed periodically.
- **SBOM scan coverage ([`SBOM-COVERAGE.json`](https://github.com/aicodeking/pandacode/releases/download/v0.3.156/SBOM-COVERAGE.json), [`SBOM-COVERAGE.md`](https://github.com/aicodeking/pandacode/releases/download/v0.3.156/SBOM-COVERAGE.md)).** Desktop build dependency scans (`pandacode-rust.cdx.json` and `pandacode-npm.cdx.json`) report 0 Critical and 0 High findings, with pre-existing lower-severity counts of 2 Medium and 3 Low in Rust and 6 Low in npm. Four compressed installers (`PandaCode-macOS-arm64.dmg`, `PandaCode-macOS-x64.dmg`, `PandaCode-Linux-x86_64.AppImage`, and `PandaCode-Linux-aarch64.AppImage`) remain `not-scanned` because `syft` cannot inspect components inside them, and the Windows setup `.exe` and macOS `.app.tar.gz` artifact inventories identify only 2 metadata components each.
- **Public website changelog deployment.** The public changelog at `https://pandacode.bambooed.ai/changelog/` is deployed separately from GitHub Releases via Cloudflare Workers (`website/README.md`) and served an earlier release (`v0.3.32`) at release time until redeployed; GitHub Releases (linked from Settings → About) and the `latest.json` updater manifest carry the current release notes.
