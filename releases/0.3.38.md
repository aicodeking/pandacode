# Connect without trusting each device, and a new mobile app look

## New

- **No more trusting each device.** Computers and phones signed in to the same GitHub account can now control each other while **Allow remote control** is on. The Trusted switch is gone from Settings → Remote access. Everything still travels end-to-end encrypted.
- **Project icons on your phone.** Computers now send each project's icon to the PandaCode mobile app, so the inbox shows the same icons as the desktop sidebar.
- **Mobile app** (`mobile/`, built from source):
  - The system tab bar with Liquid Glass. On the iPhone Duo there is a side rail and a split view with the inbox beside the open task.
  - The desktop's daily wallpapers, with visibility and blur settings.
  - An app-only Light, Dark or System appearance.
  - Messages sent while offline go out on reconnect.

## Fixes

- A computer that gets too many requests from one device at once now says it's busy right away, instead of making the device wait for a timeout.
- On the phone, threads that came up empty now load, and task lists and run states stay in step with the computer.

## Known limitations

- The first time you open a long thread on the phone, it can take a few seconds to load.
- The mobile app isn't in the App Store or Play Store yet. Build it from `mobile/` (see `mobile/README.md`).
