# Runtime web command allowlist and release-notes polish

## Security

- **Default-deny runtime allowlist for browser-tab commands.** The built-in web server (`--port` / **Settings → Connections → Remote access → Web access**, default port `47322`) now enforces `WEB_ALLOWED_COMMANDS` as a default-deny allowlist at runtime in addition to blocking desktop-only host commands (`web_blocked_command`, including `overlay_*`, `plugin:*`, embedded browser, clipboard, microphone, window chrome, Finder/Explorer and tray actions). Any unlisted or unreviewed command returns `403` before reaching the backend, backed by `every_main_window_command_is_reviewed_for_web` and `the_default_allowlist_refuses_unreviewed_commands`.

## Fixed

- **Browser-mode modal transitions and banner styles.** Restricted `.web-modal-input` transitions in `src/web-bridge.css` to `box-shadow` and merged the duplicate `.web-conn-banner` rule.
- **Release notes and updater manifest alignment.** Ensures the tagged source tree, GitHub Release page and workflow-generated `latest.json` all carry the verified web-access defaults (`47322` default port, `0` for an automatic port, `--port`/`--web-port`, `--host`/`--web-host` where `--host` requires `--port`, and `PANDACODE_WEB_PORT`/`PANDACODE_WEB_HOST` for new launches) alongside the [Local web UI](https://github.com/aicodeking/pandacode/blob/main/docs/headless.md#local-web-ui---port) documentation.

## Known limitations

- Verified locally on macOS (Apple silicon) with Rust unit tests, strict Clippy, the Node unit, design-token and release tests, the website build, and the Chromium and WebKit Playwright suites for the web bridge and Web access settings. Windows and Linux packages are covered by the GitHub Actions release builds and their startup smoke checks.
- **Session link is a full-control credential.** Anyone with the `#token=` URL has full control of your PandaCode session as the host user. CLI startup (`pandacode serve --port` or initial `--port`) prints the link to stdout (which service managers may log), and browser history can retain the initial `#token=` URL even though the page strips it from the address bar on load. Rotate the token at any time with **New token** under **Settings → Connections → Remote access → Web access** (or restart the server) to invalidate prior links.
- **Plain HTTP off loopback.** The built-in web server speaks plain HTTP without TLS. Keep it on loopback (`127.0.0.1`) and forward over SSH (`ssh -L <port>:127.0.0.1:<port> <host>`) or a private Tailscale/WireGuard network rather than exposing it directly on an untrusted LAN.
- **Desktop-only integrations.** Browser tabs do not support local voice dictation or native OS file dialogs (use the built-in path prompt instead).
- **SBOM scan coverage and reviewed exceptions (`SBOM-COVERAGE.json`).** Compressed installers (`PandaCode-macOS-arm64.dmg`, `PandaCode-macOS-x64.dmg`, `PandaCode-Linux-x86_64.AppImage`, `PandaCode-Linux-aarch64.AppImage`) are reported as `not-scanned` because `syft` finds no identifiable components inside them; build dependencies are inventoried in `pandacode-rust.cdx.json` and `pandacode-npm.cdx.json`. No dependencies changed since `v0.3.145` (`package-lock.json` and `src-tauri/Cargo.lock` dependency graphs are unchanged). Reviewed exception for carried-over upstream findings — **scope:** `pandacode-rust` (1 Critical, 1 High) and `pandacode-npm` (9 High); **reason:** pre-existing transitive dependency findings unchanged since `v0.3.145` with no new findings introduced by `0.3.146`–`0.3.147`; **owner:** `@aicodeking`; **expiry:** `2026-12-31` (or next dependency upgrade release).
