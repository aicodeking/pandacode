# A steadier response card

## Changed

- **The response block keeps the latest text.** The loading animation shows only until the first text arrives. After that, the block always holds the agent's newest text, including what it says between tool calls, and earlier text moves up into the trace when newer text replaces it.
- **Workers are quieter.** Workers in a response no longer sit on a card of their own, and they start collapsed to one line. That line says what needs you first (`1 needs attention`, `1 failed`), then how many are running. A list you open stays open.

## Fixed

- Collapsing a tool step while the agent is working now gives its height back, so no blank band stays at the bottom of the card.

## Known limitations

- A short reply can still leave some space in the card while the trace folds at the end of a turn; it is given back when the turn finishes.
- These changes were tested in the Chrome and WebKit previews, not yet in the installed app with a real agent running.
