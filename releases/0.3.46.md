# Instant first prompt on another computer

## Fixed

- **The first prompt to another computer shows at once.** Sending a New task to another computer used to leave the thread empty until the first response finished. Now your message appears in the thread as soon as you press Enter, and the agent's turn below it shows "Connecting to <computer>…", then each start stage (finding the project, downloading the repository with its percent, preparing, starting the agent), and then the response as it streams.
- If the start fails, the message goes back into the composer and the error shows above it with Retry.
- Follow-ups on a task running on another computer no longer briefly lose the prompt and the streamed reply near the end of a turn.

## Known limitations

- Tested in the preview and browser tests on macOS (Apple silicon); a start between two real computers was not tried before release.
