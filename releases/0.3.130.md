# Faster model switching and a quieter idle window, back with fixes

0.3.129 withdrew the changes from 0.3.128 and shipped 0.3.126 code under a new number. This release brings that work back (faster model and harness switching, and the quieter idle window) together with fixes for the problems that led to the withdrawal.

## Added

- **Warm agent spares.** PandaCode starts an idle agent ahead after a reply finishes, on a model, harness, effort, or permission pick in a local task, and when you begin typing a draft. At most two idle spares are kept across all harnesses and expire after 10 minutes.
- **Live Claude Code switches.** Picking an explicit model, reasoning effort, or non-**Full access** permission mode updates a waiting Claude Code process over its control channel without restarting it, and falls back to a fresh start if refused.
- **Background handshake and Codex thread preloading.** **Codex** and supported Agent Client Protocol (ACP) harnesses (**Kimi**, **OpenCode**, **Grok**, **DeepSeek**, **Command Code**, **Kilo**, **GitHub Copilot**, **Devin**, and **Hermes**) spawn and complete `initialize` ahead of your prompt, keyed to your working folder, environment, and watched login or configuration files. Local Codex tasks with an existing conversation also preload `thread/resume` without sending a turn.
- **Cold-launch racing and cancellation.** Sending a message while a handshake spare is still starting races it against a cold launch after a short grace window so a slow spare never holds up a turn. Superseded, discarded, or disabled starts cancel immediately and terminate their process groups.
- **Start agents ahead setting.** **Settings → Agents → Start agents ahead** (on by default) controls all background agent preparation; turning it off stops any starting or waiting spare right away.

## Changed

- **Instant model, harness, effort, and permission picks.** Composer choices show immediately and save in the background. Effort changes queue in order without blocking model rows or further effort picks. Leaving a named team by picking its lead model keeps your chosen reasoning effort; switching to another model or harness resets effort to **Default** (and switching harnesses keeps automatic teams when moving to **ZCode**).
- **Cached model and team catalogs.** Hovering or focusing the model button preloads the picker, and model and team lists open immediately from a 5-minute cache while refreshing in the background. Failed refreshes keep the saved list with a **Couldn't refresh** note and wait 30 seconds before retrying, updates wait while the pointer rests over the model list so rows do not jump, and **Esc** ignores active IME composition.
- **Held sends and draft preservation.** Sending from the main composer or `/btw`, starting from the board, continuing past a usage limit, **Keep fixing** in Council, and reopening **Model** or **Permissions** wait for an in-flight preference save before acting. If a save is refused, PandaCode restores the previous setting, keeps your typed draft unsent, and shows what could not be changed.
- **The settled sky lets go of the GPU.** After a quiet stretch the thread scene copies one still frame and releases its WebGL context, so an idle window no longer keeps a live scene. It wakes when you move the pointer over the sky, a run starts, or the theme or size changes. Scrolling or typing still holds the scene, and a streaming thread paints slowly instead of on every frame.
- **Hidden documents are released.** Diffs, PDFs, spreadsheets, and images drop their decoded data when the window is hidden or you leave the tab. Coming back keeps the page, scroll, and pan you had.
- **A new task opens without waiting on agent discovery.** The first screen and New task no longer wait for the list of installed agents. That list fills in behind the thread you already have.
- **A long diff keeps your place.** Folding, switching Unified, Split, or Wrap, and scrolling a virtualized diff restore the line you were reading.
- **Very long messages stay light.** A message over 128 KiB shows a shortened preview ending in a **[Message preview truncated at 128 KiB…]** notice. Editing or copying it still uses the full text.
- **The Changes view holds less text.** Diff text kept for off-screen files is capped at 16 MiB; files beyond it reload when you scroll back to them.
- **The crash guard notices sooner.** It is told by the system when the app's process exits instead of checking for it, and the crash guard and local signing keep their files in the app's own data folder.

## Fixed

- **A picked model sticks.** A task list refresh that was read before your pick no longer puts the old model back, so the model button no longer blinks back and the switch no longer reverts.
- **Re-picking the current model just closes the picker.** Choosing the model that is already selected changes nothing and starts nothing, except inside a named team, where picking its lead model leaves the team.
- **The busy pulse stays steady.** The pulse on the **Model**, **Permissions**, and send buttons while a pick saves keeps its rhythm when the composer redraws instead of restarting.
- **Picks save in the order you made them.** Model and permission changes save one at a time, so the last pick is the one kept. A refused pick returns to the last saved choice, and **Permissions** stays busy until its last pick lands.
- **A harness pick keeps its own agent started ahead.** Picking a harness as a reply finishes no longer has its agent replaced by the one started for the end of the turn.
- **The agent started ahead survives more changes.** Changing the model, permissions, team roster, or Council keeps the agent started ahead whenever the change can be applied in place, instead of throwing it away.
- **Stale running tasks no longer refuse a switch.** A task still marked as running after its agent stopped is reconciled, so a model or harness switch goes through.
- **Exited spares no longer count as ready.** A spare whose process has quit is dropped instead of being handed a turn.

## Privacy

- **Local CLI preparation only.** When **Start agents ahead** is on, PandaCode starts only the agent CLIs you installed and selected, and sends no user prompt (local Codex tasks with a saved thread load that conversation ahead without sending a turn). Starting a CLI can still connect to its provider and run startup hooks, plugins, or MCP servers from your own configuration; **Turn off agent telemetry** still applies. Model catalog caching keeps lists in memory only and never polls in the background.
- No other new network requests. Parking the sky and releasing hidden documents happen on your machine.

## Known limitations

- Warm spares are not started for key-based Claude Code relays (**GLM Coding Plan**, **MiMo Token Plan**, **Alibaba Token Plan**), **Antigravity**, **Cline**, **Cursor**, **ZCode**, **Muse**, **Pi**, or **omp**, nor for cloud tasks, Connect remote mirrors, agent-team leads and workers, `/btw` side-thread picks, or skill, `/goal`, `/compact`, and `/review` turns.
- Switching a waiting Claude Code spare to or from the `default` model alias, into or out of **Full access**, or across fast-mode or conversation changes restarts the spare instead of updating it in place. OpenCode 2.x sign-ins stored in `opencode.db` are not watched by file key.
- In a very deep Wrap or Split diff, rebuilding the view can still restore a pixel position rather than the line, so the reading place can slip.
- Checked locally with the TypeScript unit tests, the Rust library tests against local fake-CLI harnesses, and Chromium Playwright browser tests. End-to-end switching latency against live provider servers has not been benchmarked, and desktop installers were not built or tested on native machines before CI.
