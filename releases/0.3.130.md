# New model cards and automatic worker routing

## Added

- Embedded model cards for Claude Fable 5.2, GPT-6.2 Sol, GPT-6.2 Astra, Gemini 4 Carbon and Gemini 4 Hydrogen.

## Changed

- Automatic worker routing can select models advertised by an installed harness and enabled for teams.

## Known limitations

- Capability scores are routing estimates, not verified benchmark results.
- Model cards do not guarantee account access. The Antigravity account used during preparation does not yet advertise Gemini 4; those models become eligible for routing only when the harness advertises them and they are enabled for teams.
