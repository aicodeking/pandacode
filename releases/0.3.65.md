# Smarter teams: Panda Router v4 and one Team menu

## New

- **Pick your team from the Team button.** Clicking **Team** now opens one menu: **No team**, **Cheap team**, **Balanced team** or **Best team**. The button shows what is on (for example "Balanced team"), and new tasks start on the kind you used last. This replaces the separate worker-models chip. If model routing is off, **Team** (the lead picks models) is still there, and the three kinds say they turn routing on.
- **Panda Router v4.** Routing now uses PandaOrchestrator's v4 model: a learned success estimate per model, costs that include what a failed attempt costs, and an **escalation ladder** of models to try in order. It still runs on your computer and the profiler is still downloaded once (about 35 MB, from a new pinned commit, verified by SHA-256).
- **Workers start cheap and move up only when needed.** In Cheap and Balanced teams, each routed worker starts on the cheapest model likely to pass. The lead checks the result with tests, a typecheck or a review. If it fails, the lead replaces the worker and Panda Router picks a stronger model than every one that already failed. It never steps down. After two retries the lead reports the failure to you instead of trying again. Best team starts on the strongest fit.

## Changed

- Routing defaults to **Balanced** with a minimum chance of success of **50%**, which you can set between 30% and 90% in Settings → Agent teams → Model routing. If you never changed the old 80% default, it moves to 50%; v4's estimates are stricter, so 75% or more rarely leaves any model to choose.
- The old profiler files are removed once the new ones load.

## Known limitations

- Success estimates are calibrated against a strict judge, so even easy tasks show about 40–60%. Compare models with each other, not against 100%.
- Escalation needs a real check. The lead decides whether a result failed, so the retry loop is only as good as the tests or review it runs.
- Intel Macs and x86_64 Linux still route with the keyword heuristic, as before.
