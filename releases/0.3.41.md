# See what you attached

## New

- **Attachments in the conversation**: your messages now show what you attached, with the same chips as the prompt box, instead of a folded "Attached context" block. Click one to open it:
  - project files and documents open in a tab;
  - files and folders outside the project are shown in Finder or Explorer;
  - images, screenshots and mockups open larger;
  - GitHub issues and pull requests open in your browser.
  Anything else shows the text that was sent. Older messages show chips too.
- **Drop anything on the prompt box**: a dropped file that can't be attached (an unsupported type, too large, or an image for a harness without image input) now goes into the prompt as its path, so the agent can open it itself, instead of failing.

## Known limitations

- Images sent before this version, and images older than 7 days, can't be shown again; their chip opens the text that was sent with them.
- A file dropped in the browser preview has no path, so only its name is inserted.
