# The phone app catches up with the desktop

## New

- **Much more of PandaCode on your phone.** With PandaConnect, the phone app can now:
  - **Threads:** rename, archive (with Undo), delete, fork, export, rewind and search them.
  - **Composer:** use slash commands, By the way questions, the message queue, attachments (photos, camera and files) and @-mentions of files.
  - **Git and GitHub:** commit, push, switch branches, manage worktrees and discard changes. Browse the GitHub view, open pull requests and review them.
  - **Your computer:** browse and edit project files, search them, and run checks, skills, recipes, run scripts and a terminal.
  - **Admin:** manage schedules, bot settings, local machines and cloud agents, designs and moodboards, and computer settings.
- **Laid out for small screens and iPhone Duo.** The sidebar and its toggle sit in the native header. Screens leave room for the sidebar in split view. Text sheets ask before discarding what you typed. Screens reload when your computer comes back online.
- The phone shows features only when the connected computer supports them. If the computer runs an older PandaCode, the phone asks you to update it.

## Fixed

- **Linux microphones saved in 0.3.108 work again.** Settings → Voice lists sound cards by their names again, and a microphone picked in 0.3.108 shows as connected and records instead of falling back to the system default. Microphones picked in 0.3.109 by their raw ALSA id still match. The raw ALSA ids (such as `hw:CARD=PCH,DEV=0`) are still listed alongside the card names.

## Changed

- **PandaConnect is sturdier.**
  - Slow requests (searches, previews, merges) run in their own lanes with time limits, so they no longer hold up quick ones.
  - A start or send whose reply was lost is never applied twice.
  - After reconnecting, the phone catches up cleanly.
- **Tighter phone access on your computer.**
  - Access levels are View, Control and Full, plus the **Full access for remote tasks** switch.
  - The phone can't read secret files, links that point outside the project, or projects rooted at your home folder.
  - Git run from the phone never runs programs named in a project's own config.
  - GitHub actions stay inside the project's repository.
  - Answering a bot's approval prompts, or driving a bot's queue or schedules, now needs Full access.

## Known limitations

- The new phone features need the matching phone app build. Phones on an older build keep working with the features they already had.
- iPhone Duo and native phone behaviour were checked against the code and in tests, not on a real device.
- Photos aren't shrunk before upload, so full-size camera photos can hit the 5 MB attachment limit.
- If your computer restarts while a task is being started from the phone, retrying can start the task twice.
- Renaming or pinning a bot's conversation from the phone needs only Control access.
- In a fork checkout, pull request actions from the phone use the upstream repository, while the desktop GitHub view shows your fork.
