# Clearer model picker errors

## Changed

- **A harness whose models couldn't load is disabled in the model picker.** The "Could not load models for…" line under the list is gone. The harness is dimmed and its models can't be picked; hover its tab, its **Unavailable** label or a model to see the error. Reopen the picker to try again.

## Known limitations

- While a harness's model list is failing, you can't enter a custom model ID for it from the picker.
