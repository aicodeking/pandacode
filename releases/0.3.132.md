# Turn-card error alignment and right sidebar persistence

## Fixed

- **Turn-card error controls alignment**: The dismiss (`×`), disclosure, and **Dismiss all** controls in error rows inside turn cards now align flush with the card's right edge when the floating action dock sits clear of the card column, and shift inward only by the actual dock overlap in narrow panes or right-side thread tiles.
- **Right sidebar staying hidden across threads and restarts**: Hiding the right sidebar is now remembered across threads and restarts, so switching to threads that previously had the inspector open no longer reopens it automatically. Each thread still keeps its own inspector tab, expanded folders, selected file/diff, and browser URL when you show the sidebar again.

## Known limitations

- Agent-initiated previews (for example opening the browser preview after running a project) still open the right sidebar in that active thread without changing your saved hidden preference for other threads.
