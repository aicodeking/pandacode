# See every pooled account's email and usage at a glance

## Changed

- **Redesigned accounts in Settings → Providers.** Claude Code and Codex each get one card with the Account pool switch, a Refresh button and when usage was last checked. Every account is a single row:
  - its name, with the signed-in email and plan underneath (for example "you@example.com · Max"), plus how many tasks are running on it;
  - a status chip: Ready, Near limit, the limit that ran out with its reset ("Weekly limit · until Sat 11:44 AM"), Not signed in, Same login or Left out;
  - 5-hour and weekly usage bars with reset times: grey below 70%, amber from 70%, red only at the limit;
  - an **In pool** switch and a ⋯ menu for Try now, Copy sign-in command, Edit (opens under the row) and Delete (asks first, and says the sign-in stays in its folder).
  
  **Add account** starts the browser sign-in; setting an account up by hand is folded away.
- **Accounts in the Usage panel.** Each Claude Code and Codex account shows its email and plan, the same status chip and the same two usage bars as Settings. An account that shares another's login says so instead of repeating its numbers, and one that isn't signed in links to Settings.

## Privacy

- The email and plan are read locally from each CLI's own login files (Claude Code's `.claude.json`, the ID token in Codex's `auth.json`). Only those two fields are read, never a token, and they are only shown in the app.
- Settings now checks each pooled account's usage when the accounts card is shown, then at most every 5 minutes or when you press Refresh. These are the same plan-usage requests the Usage dialog makes, to each account's own provider; the README privacy table and the website privacy page list them.

## Fixed

- Opening Settings → General no longer redraws the running-agents widget settings a moment later when nothing changed.

## Known limitations

- The redesign was checked with the browser test suite and screenshots in light and dark themes, not by hand in the installed app with several real accounts.
