# Cursor CLI, clearer tool headers and safer skill updates

## Added

- **Cursor CLI.** Run Cursor tasks in PandaCode through the Agent Client Protocol (ACP), with model and effort selection, Plan mode and command approvals. Uses your installed Cursor CLI and its sign-in.

## Fixed

- **Thinking stays together.** The Thinking label and its expand arrow stay on the same line.
- **Long activity headers fit.** Tool headers in threads and the launcher, including **Earlier in this turn**, now shorten with an ellipsis. Running, failed and stopped counts and the expand arrow stay visible on the same line.
- **Alibaba handoffs appear on mobile.** Agent-switch notices involving Alibaba Token Plan now appear in the conversation.
- **Skill updates protect files you added.** An update to an active skill refuses before writing anything if a new file would overwrite one PandaCode did not write.
- **Failed skill updates restore the previous version.** This works in projects and your home folder. Files changed in the meantime are kept, and the error names anything that could not be restored.
- **Turning skills off cleans up correctly.** Empty skill folders no longer block turning a skill on again. Only the skill's own recorded Git exclude entries are removed, including after a skills-folder link was replaced with a real folder; unrelated entries stay.
- **Safer skill destinations.** Projects whose Git configuration points outside their own repository no longer get exclude entries. Home-folder skill and rule updates check for regular files before rewriting them.

## Known limitations

- Cursor plan usage must be checked in its dashboard, and dashboard-managed MCP servers are unavailable. Interactive question pickers are skipped; the agent is asked to put questions in its reply instead. Cursor slash commands appear after a task has run.
- Some Git exclude entries from 0.3.114 or earlier remain when the project is a subfolder of its repository, to avoid removing entries you may have added yourself.
- Home-folder skill and rule updates still rewrite files in place and follow filesystem links.
