# Closing the window no longer loses PandaCode, and a batch of community fixes

## Fixed

- **Closing the main window keeps a way back (#305).** On macOS and Windows the close button now hides the window. **Open PandaCode** in the menu bar, a Dock click and launching the app again all bring it back, and running agents keep going. On Linux, where a tray icon can be invisible, closing quits the app and stops its agents.
- **Enter and Esc during Japanese, Chinese or Korean input.** The Enter that commits a conversion no longer sends the message or picks a menu item, and Esc that cancels a conversion no longer stops the agent. This covers the prompt, launcher, side thread, command palette, model picker, find in thread, slash and @ pickers, and the other text fields. Thanks @oden-wa.
- **Dragging on macOS.** Text can be dragged into the prompt, and sidebar thread drags and moodboard drops reach the app. Dropped files and folders keep their real paths. Thanks @superheher.
- **Models for teams (#315).** A recently used model can now be turned off without switching off the whole harness, and models with the same name show their ID. Thanks @samgsx.
- **Agent usage.** Reads Claude Code logins stored in the Keychain and OpenCode 2.x credentials, without repeated Keychain prompts. Thanks @TheOneBestAgent.
- **Cline tasks get PandaCode tools.** Cline doesn't advertise HTTP MCP over ACP, so these tasks used to stop with an error. They now connect through a private settings file that lasts only for the run; your own Cline settings are untouched and nothing is downloaded. Thanks @TheOneBestAgent.
- **Mobile transcript on iOS 27.** The task transcript keeps painting at rest. Thanks @zj-linjie.

## Added

- **Android emulators on Linux (#216).** The Simulators tab now shows on Linux, Android only, and a crash while booting is reported at once. Thanks @chesedo.
- **Antigravity through the `agy` CLI (#306).** With no `agy_acp_server` installed, PandaCode uses `agy acp`. Thanks @YrFnS.
- **Environment variables and an executable location for every agent (#210, #220).** Codex and Kimi Code now have settings cards, and Claude Code accepts a custom location, which GLM and MiMo follow. Thanks @hongkongkiwi.

## Docs

- The README describes team worker limits correctly and mentions Classic team setup (#267).
- The bots guide covers WhatsApp live messages that never arrive after the webhook verifies (#270).

## Known limitations

- Closing and reopening the window, and all drag and drop on macOS, were checked by code review and automated tests, not by hand in the installed app. If dropped folders or documents lose their paths, please open an issue.
- The iOS 27 transcript fix was not run on an iOS 27 device, and a long thread may flicker briefly as it opens there.
- The `agy acp` fallback was not run through a full signed-in session here. The Linux emulator boot and the Windows and Linux close behaviour were not run on those systems.
- On Windows, text drops, thread drags and moodboard drops are still swallowed by the native drag handler.
