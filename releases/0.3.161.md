# Project removal from switcher, Codex pool failover, Web/Tailscale settings, draft attachments, debug bundles, and reliability fixes

## Added

- **Remove or close projects directly from the project picker (#414).** Every project row in the project switcher now offers a hover/focus Remove action wired to the confirmation dialog (removing the project and its tasks from PandaCode without touching files on disk), including projects whose folder was already deleted.
- **Web access bind address and trusted host names in Settings (#418, #442).** Configure the Web UI bind address (`host`) and trusted host names (`allowedHosts` / `--allowed-host`) directly in Settings for Tailscale Serve / MagicDNS setups without CLI flags, with strict `Host`/`Origin` matching and desktop-only write protection.
- **Appearance reading-width option (#431, #432).** Choose between Comfortable and Wide conversation/composer column widths in Settings → Appearance.
- **Command Code plan usage in Agent Usage (#433, #434).** Displays Command Code billing credits and usage summary when a Command Code key is configured.
- **Model selections recorded in desktop task exports (#402, #450).** Desktop task exports now include the requested harness, model, and effort alongside Claude's reported model ID, backed by an additive SQLite table (`task_model_runs`) with strict export allowlisting.
- **Shared bot rooms over PandaConnect (#444, #445).** Exposes `rooms.list`, `rooms.messages`, and `rooms.post` over Connect (and the mobile client) with grant and remote-team checks.
- **Redacted debug session export and fix-thread starter (#439, #440).** Export a redacted Markdown debug bundle or open a pre-seeded fix thread that preserves the source session's permission mode (`task.mode`) while keeping `save_debug_bundle` desktop-only.
- **Refreshed bundled model price snapshot (#456, #457).** Regenerated the bundled pricing snapshot and added a weekly GitHub Actions refresh workflow.

## Fixed

- **Expired Codex logins are skipped and pooled Codex accounts fail over cleanly (#437, #438).** Checks local Codex OAuth JWT expiry before launching and fails over to another pooled account on unrefreshable auth failures.
- **Signed-out harnesses stay out of Panda Router and automatic teams (#436).** Filters out harnesses lacking a valid login while keeping Codex JWT-expiry validation and preserving Claude macOS Keychain logins.
- **Unsent draft attachments survive restarts (#413, #441).** Persists validated composer draft attachments in local storage across app restarts, restricting restored image thumbnails strictly to `data:image/` URLs.
- **Headless web allowlist wire names and `serve` crash-guard relaunches (#446, #447).** Fixed wire command names (`delete_session`, `model_routing_status`, `model_routing_configure`), preserved `serve` flags across restarts, and added `--version`.
- **Team saves recover when another build drops `architect_team_meta` (#451, #452).** Automatically drops dangling tracker triggers and falls back to snapshot reads/writes instead of failing team saves with `no such table: architect_team_meta`.
- **Inset shell frame gap stays constant under Interface size zoom (#429, #430).** Keeps `--inset` in native points (`calc(8px / var(--page-zoom, 1))`).
- **Unicode spaces preserved in `clip()` (#435).** Preserves non-ASCII spaces such as macOS screenshot `U+202F` so displayed file paths still match files on disk.
- **Stabilized Linux crash-guard exit test and fixed documentation links (#443, #448).** Isolated the `crash_guard::link` pipe fd test to eliminate flaky Linux CI failures and repaired broken cross-doc links in `docs/agent-reference.md` and `CONTRIBUTING.md`.

## Known limitations

- **Local web access (`--port`) ([`docs/headless.md`](https://github.com/aicodeking/pandacode/blob/v0.3.161/docs/headless.md#local-web-ui---port)).** The `#token=` URL grants full control of the PandaCode session as the host user (including starting agents, running terminal commands, and editing workspace files). The built-in web server speaks plain HTTP, so keep it on loopback (`127.0.0.1`) or reach it over an SSH tunnel, Tailscale, or WireGuard rather than exposing it on an untrusted network. Host-only capabilities — local voice dictation, the embedded browser, native clipboard access, and OS file/tray actions — are unavailable in browser tabs.
- **SBOM scan coverage ([`SBOM-COVERAGE.json`](https://github.com/aicodeking/pandacode/releases/download/v0.3.161/SBOM-COVERAGE.json), [`SBOM-COVERAGE.md`](https://github.com/aicodeking/pandacode/releases/download/v0.3.161/SBOM-COVERAGE.md)).** Generated during the release build; compressed installers (`.dmg` and `.AppImage`) remain `not-scanned` because `syft` cannot inspect components inside them, while the Rust and npm lockfile SBOMs cover shipped dependencies.
- **Public website changelog deployment.** The public changelog at `https://pandacode.bambooed.ai/changelog/` is deployed separately from GitHub Releases via Cloudflare Workers (`website/README.md`); GitHub Releases (linked from Settings → About) and the `latest.json` updater manifest carry the current release notes immediately.
