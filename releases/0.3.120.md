# Sharper tool-call rows

## Improved

- **MCP tools read as what they did.** An MCP tool that changes something reads `Used <tool> …` rather than a passive description. One that deletes or drops data, judged by its name or by the SQL it sends (`DROP`, `TRUNCATE`, `DELETE FROM`, `ALTER TABLE … DROP`), carries the `destructive` badge.
- **Third-party screenshots get thumbnails.** Screenshot tools from other MCP servers (Puppeteer, Playwright and browser-capture tools) now show a thumbnail and read `Took a screenshot`, like PandaCode's own. Only a tool's own name counts, never its server name or a shell runner's title, and the app and the image server follow the same rule.
- **Clearer blame when a later step fails.** When the first command ran but a later one failed, the `+N more commands` tail is shown in the failure colour and the lead step is muted, so the row no longer looks like the first step failed.
- **More risks flagged.** Writing to shell startup files or system configuration, `sed -i`, `tee -a` appends, `dd` to a raw disk, `kill -1`, deleting a GitHub repository, release or issue, and `xargs rm` (now `Deleted files listed by …`) are all flagged. Long commands are checked for these too. Steps skipped by `||` and a failing `make` target are attributed correctly.
- **Tidier cards and narrow rows.** A search with no matches shows a quiet badge. Exit codes use a single pill, and "Not applied" is in sentence case. A snapshot's image isn't shown twice, and stopped steps are counted. Long image names end in an ellipsis, and the file chip keeps a minimum width in narrow windows.

## Known limitations

- Destructive MCP calls are recognised from the tool's name and any SQL text it sends. A tool with a neutral name that deletes data through other arguments is not flagged.
- An MCP search whose `query` text mentions SQL words (for example "how to truncate a string" or "DELETE FROM example") can be marked `destructive` and lose its `Searched for` sentence. SQL past the first 2,000 characters of an MCP call is not checked.
- If a test run passes every test but still exits non-zero (for example on a coverage threshold), a deletion after `||` can be shown as not run.
- Editing (not writing) a shell startup file or system file with the Edit tool is not flagged. MCP tools named `remove_…` (such as `remove_label`) are flagged as deleting data.
- In very narrow rows (about 350px) a short result such as `· 131 passed` or a line range can be cut away before the `+N more commands` tail.
- Thumbnails for PandaCode's own design, progress-snapshot and moodboard-image tools may fail to load when the image path appears only in the tool's output.
