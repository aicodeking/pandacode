# Fix model selection when ZCode is installed

## Fixed

- Selecting a model no longer fails with “Worker profiles need unique IDs and an installed harness type” when ZCode is installed and an automatic team is enabled. Automatic teams now leave ZCode out of their model catalog because it does not support team tools yet.
- Selecting a ZCode model turns off an unused team and runs it as a single agent. Switching back to another harness keeps working.

## Known limitations

- ZCode cannot lead or join agent teams yet. If a team has already run workers, start a new task to use ZCode; the existing team history is preserved.
- The model-picker fix was verified in Chromium and WebKit. Packaged installers have not been tested by hand on real hardware.
