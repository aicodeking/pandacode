# Linux, Windows import and harness fixes

## Fixed

### Linux

- **Ctrl+Z and Ctrl+Shift+Z undo and redo in the composer** and other text fields, which WebKitGTK didn't do on its own (#277).
- **Pasting a copied image works on Wayland**, including screenshots from Flameshot, when the paste carries no file (#272). Large images are scaled down before they're attached.

### Harnesses

- **ACP harnesses without the selected mode keep running.** A harness that has no Plan or Accept edits mode now runs in its own current mode and says which one it used. It refuses instead if that mode looks more permissive than the one you picked (#269).
- **Claude Code no longer shows as Unavailable** when its startup reply is over 256 KiB (#276).
- **DeepSeek harness skills appear in the slash menu** (#278).
- **The capability inventory finds OpenCode MCP servers set up in `opencode.jsonc`**, including files with comments and trailing commas (#275).

### Projects and import

- **Importing conversations works on Windows.** Codex conversations were filtered out because of how Windows writes folder paths, so the import listed nothing (#273).
- **A project whose folder you renamed or moved can be relinked.** "Project folder is unavailable" now offers Locate folder. Its worktrees are repaired to point at the new location (#268).

### Interface

- **Cloud sandboxes settings:** the environment checkbox is normal size with its help mark beside it, and connected providers are listed first (#283).

Thanks to @hongkongkiwi and @AbuSeRik for the pull requests these fixes started from.

## Known limitations

- The Wayland paste and Linux undo fixes were tested in browsers, not on a real Linux desktop.
- The Windows import fix was tested with Windows-style paths on macOS, not on Windows. Importing Claude Code conversations on Windows looked correct in the code, but we couldn't reproduce the report.
- PandaCode decides whether a harness mode is more permissive by its name, so a permissive mode with an unusual name could still be used.
