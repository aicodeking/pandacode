# A better menu bar

## New

- **A glass panel under the panda.** Clicking PandaCode's menu bar icon now opens a slim panel instead of a plain menu: running tasks with a spinner, tasks that need your approval or answer, and finished tasks with a check or cross, each with its agent and project. Click a row to open the task; arrow keys and Enter work too.
- **Plan usage with bars.** Each agent's plan limits show as thin bars with reset times, turning orange from 80% and red from 95%. Use the refresh button to check again; nothing is checked in the background.
- Right-click the icon for Open PandaCode and Quit.

## Known limitations

- The finished list is kept in memory and starts empty after PandaCode restarts.
