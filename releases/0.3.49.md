# PandaCode Connect: direct routes, pairing and diagnostics

## New

- **Direct connection on your own network.** When two of your computers are on the same local network or Tailscale, Connect now opens a direct link alongside the relay and uses whichever answers. It is end-to-end encrypted like the relay, each device proves its key before connecting, and addresses are only shared inside encrypted messages. If the direct link drops, traffic moves back to the relay at once.
- **Approve new devices.** A new device now waits for approval on the host. Choose View only, Control or Full access, or Block it, and compare the key fingerprint shown on both screens. A device whose key changes must be approved again. You can also pair with a one-time 6-digit code (10 minutes, single use).
- **Connection diagnostics.** Settings → Remote access → Diagnostics shows each connection stage, the route and response time to each device, and recent connection events, with Reconnect now and Copy report. The report leaves out tokens, keys, IP addresses and file paths.

## Fixed

- After a reconnect, the desktop and the phone replay exactly the events they missed, in pages, and reload the conversation if too much was missed.
- Retrying a failed start no longer replays the old failure, and a start whose reply was lost can still be stopped.
- Stop on a remote start only reports "stopped" once the other computer confirms it.
- Retry really reconnects; going offline or online no longer closes the @ menu; your first prompt stays visible after a steer; permission and "waiting for approval" errors show inline.

## Known limitations

- On upgrade, devices that are online at the first check keep Full access; a paired device that is offline then needs a one-time Approve.
- The phone app still connects through the relay only.
- An unapproved (but not blocked) device on your account can still trigger a direct-route probe of private addresses it announces.
- Not yet tested between two real computers on every platform.
