# Devin CLI

## New

- **Devin CLI** is a new harness. Install it (`curl -fsSL https://cli.devin.ai/install.sh | bash` or `brew install --cask devin-cli`), run `devin auth login` once, then pick **Devin CLI** in the model picker. PandaCode talks to `devin acp` with that sign-in. If `devin` isn't on your PATH, the copy bundled with Devin Desktop is used.
- **Every Devin model, with its own thinking levels.** The picker lists Devin's whole catalog (about 110 models). Each regular model shows only the thinking levels it supports. The list loads in a few seconds without sending a prompt, and is kept for five minutes. It opens on your task's model, your recent ones and Devin's top picks; search finds the rest. Text-only models are labelled, and a task with images on one stops before sending.
- **Devin's own modes.** Standard is Devin's Code mode: edits inside the project apply, and commands Devin doesn't judge safe ask you. Plan mode is Devin's Plan mode, which ends with an **Implement this plan?** approval. Full access is Devin's Bypass Permissions. Approving a request allows that one action only, never "always allow" or a switch to bypass.
- **Quick follow-ups.** A follow-up on the same model, effort and mode goes straight to the prompt, and a message you send while Devin works joins the running turn.
- The task console opens Devin's REPL on the same session. Devin's slash commands and skills appear in the composer; its account and mode commands (`/login`, `/bypass`, …) stay with the CLI and PandaCode's mode picker.
- Model discovery and command discovery delete their empty sessions, so they don't show up in your Devin history.

## Known limitations

- Fusion models are listed without a thinking-level slider and use the effort Devin has saved for them.
- Devin's plan limits aren't shown in the Usage dialog; its ACP server doesn't report them.
- The console can't start in Plan mode (Devin's REPL has no Plan permission mode); use task chat or type `/plan`.
- Tested on macOS (Apple silicon) with Devin CLI 3000.11.216. Windows and Linux were not tried before release.
