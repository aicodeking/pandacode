# PandaCode — SUP3RMASS1VE modified version

This is a fork of [PandaCode](https://github.com/aicodeking/pandacode). Thank you to [aicodeking](https://github.com/aicodeking) and the PandaCode contributors for the original app and its open-source foundation.

## New and improved

- Click the total beneath the composer to see a task's tokens, cached usage and estimated API cost, with a breakdown by model. Totals update after each response.
- Save file checkpoints before local agent turns, compare saved checkpoints, and preview a rewind before restoring files into a forked conversation.
- Keep live reply cards compact after tool output folds.
- Clarify this fork's attribution and point README downloads to this repository's releases.

## Platforms and limitations

- Builds for macOS Apple silicon and Intel, Windows x64 and ARM64, and Linux x64 and ARM64.
- Mac apps use verified ad-hoc signatures. Downloaded apps may still require the first-launch quarantine step in the installation instructions below.
- Task usage currently reads available local Codex and Claude Code logs. Missing logs or prices are shown as unavailable or partial. Costs are API-equivalent estimates; separate worker tasks are excluded.
- Checkpoints apply to supported local Git checkouts. Ignored, oversized or otherwise excluded files are not restored. Stop agents and close terminals using the checkout before rewinding.
- macOS was built and checked locally. Windows and Linux packages receive automated startup checks in Actions; their interfaces have not been checked on physical machines for this release.
