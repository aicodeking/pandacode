# Glossary

| Term | Meaning |
| --- | --- |
| Project | A folder opened in PandaCode, used as the working folder for its conversations. |
| Change task folder | Click the folder icon in a new task’s composer, or the project name in its heading, to choose an existing project. Choose Open project… → Browse… to select another folder. The task keeps its draft and model. |
| Conversation | The saved messages within a task or chat. |
| Task | A conversation listed in the sidebar, with its agent and project settings. |
| Move to project… | Keep the conversation and use a different project folder for future messages. Files stay in their original folders. |
