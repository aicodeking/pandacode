# Local VMs

Moved verbatim from `AGENTS.md`, which keeps a short summary of each bullet. Paths and links below are relative to the repository root.

- Local VMs (Apple silicon): `src-tauri/src/vm*` drives Tart (`vm/tart.rs`; one-click install of the notarized release in `vm/setup.rs`, team `9M2P8L4D89`) on Virtualization.framework. VMs run headless with `--vnc-experimental`; `vm/rfb.rs` is a small RFB client (that server answers only when the screen changed, so captures are incremental with a quiet window) and `vm/screen.rs` maps clicks, drags, scrolls, typing and key combos, scaling screenshots to 1280 px wide. Commands run through `tart exec` (Tart Guest Agent, no SSH). New VMs start right away, and a Linux VM without a desktop gets one in the background whenever PandaCode starts it (`vm/desktop.rs`). The panel draws frames on a canvas: the app CSP allows no `blob:` images, and `tests/vm.spec.ts` runs under that CSP. Linux guests start at 2 GB; idle VMs are suspended (macOS) or stopped (Linux) after `vm::IDLE`, and on quit. Agents get `pandacode_vm_*` tools (`vm/tools.rs`); the inspector's VM tab is `src/vm-panel.ts`, mocked in `src/preview-vm.ts`. Live tests are `#[ignore]`d and take `PANDACODE_VM`/`PANDACODE_VNC`.
