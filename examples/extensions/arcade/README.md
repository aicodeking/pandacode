# Arcade (`sample.arcade`)

A panel and nothing else: a snake on a canvas in a package with no runtime, no service and no process. It is the reference
for panel assets, page state and keyboard handling (see `docs/extensions/examples/arcade.md`).

Install the `package/` folder as a trusted package; it asks for `ui.contribute`, `ui.richViews` and `storage.private`.
Open it with the **Arcade** button in the workspace header or the command **Open arcade**.

Files of `package/panel/`: `index.html`, `style.css`, `main.js`, `game.js`, `audio.js` (three modules), `level-worker.js`,
`sprite.svg`, `point.wav`, `over.wav`.
